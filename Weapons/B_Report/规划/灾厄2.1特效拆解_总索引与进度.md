## 第 0 篇要点回顾（供快速索引）

**五个层级**
- **L1** 原版 `Dust` + 灾厄 `ModDust`（约 25 个）— 做"量"
- **L2** `GeneralParticleHandler` 粒子（117 个类）— 做"质"
- **L3** `PrimitiveRenderer` 图元带 + 60 余个 `.fx`
- **L4** `Metaball`（20 余个）— 唯一能做"融合"的层
- **L5** `ScreenShaders` 全屏后处理

**必须记住的三条硬约束**
1. `SpawnParticle` 在超过 `CalamityClientConfig.Instance.ParticleLimit` 时**静默丢弃**非 `Important` 粒子 → 滥发粒子会挤掉自己的关键高光
2. 成组特效（环、扇、星座）必须先查 `FreeSpacesAvailable()`，否则会画出残缺的半个环
3. 图元带硬上限：`MaxPositions 1000` / `MaxVertices 3072` / `MaxIndices 8192`

**曲线词汇表**
| 曲线 | 观感 | 用于 |
|---|---|---|
| `sin(πt)` | 淡入+淡出对称，峰值在中点 | 凝聚（`GenericBloom` / `StrongBloom`） |
| `cos(t·π/2)` | 一出现就最亮，单调衰减 | 爆发（`BloomParticle` / `PulseRing`） |
| `PolyOut^4` | 前 30% 冲到位，后 70% 几乎静止 | 冲击波扩张 |
| `pow(t, 3)` 淡出 | 前 60% 不褪色，最后 20% 断崖消失 | 高速火花的锐利感 |
| `pow(t, 8)` | 前 80% 几乎为 0，最后 20% 暴涨 | "临界点"提示（Fetid Emesis 光环、Starfleet 前推） |
| `sqrt(1-(t-1)²)` | 瞬间弹出后减速到位 | `LineVFX` 的线条射出 |

**双绘制技巧**：`SparkParticle` / `GlowSparkParticle` / `CustomSpark` 都把同一张图画两遍——外圈宽、内圈 `×0.45` 窄，加法混合叠出**过曝白心 + 彩色外晕**。零 shader 成本的"高能量"表现。

## 反复出现的设计规律（跨武器归纳）

1. **规整骨架 + 随机填充**：爆炸里碎石/环用 `TwoPi / n * i` 完美均分保证"是个圆"，烟雾用 `RotatedByRandom` 保证不呆板。
2. **一个随机数控制多个属性**：Starfleet 的 `variance` 同时决定角度、尺寸、速度 → 天然的锥形物理衰减，比 roll 三次随机数更"对"。
3. **尺寸与速度反相关**：`scale = k * (1.1 - power)`，`velocity = vel * power`。飞得快的小、飞得慢的大 → 喷发透视感。（Seadragon 眼部、Starfleet 枪尾）
4. **双层速度差表现方向性**：两个环，一快一慢、一小一大。（Megalodon 枪口、Relic of Deliverance 冲刺）
5. **扩张环 = 释放，收缩环 = 聚集**（`originalScale > finalScale` 的反向 `CustomPulse`）。
6. **状态提示画在玩家会看的地方**：Firestorm Cannon 把过热画在枪身而非空中。
7. **多通道冗余编码**：Nullification Pistol 用射速 + 音高 + 额外尘 + 爆炸消失四个通道同时表达"资源耗尽"。
8. **系列武器的密度应阶梯上升**：Megalodon 6 实体/发 → Seadragon 8 → Voidragon 17。全部拉满会让强度差消失。
9. **安静的中段让终爆显得大**：Blissful Bombardier 巡航期每帧仅 1 个烟。
10. **内置降级开关**：Dryad's Tear 的 `reduceVisuals`，同屏多份时自动削减循环次数。
