## 第一部分：潜伏（Stealth）系统完整解剖

文件：`CalPlayer/CalamityPlayer.cs`（字段 + `UpdateStealth` 系列方法）、`Balancing/BalancingConstants.cs`

### 1.1 核心字段

```csharp
public float rogueStealth      = 0f;     // 当前潜伏值
public float rogueStealthMax   = 0f;     // 上限（由盗贼套装提供，无套装则为 0）
public float stealthGenStandstill = 1f;  // 静止回复倍率
public float stealthGenMoving     = 1f;  // 移动回复倍率
public bool  stealthStrikeThisFrame  = false;
public bool  stealthStrikeHalfCost   = false;   // 潜伏消耗 50%
public bool  stealthStrike75Cost     = false;   // 潜伏消耗 75%
public bool  stealthStrike90Cost     = false;   // 潜伏消耗 90%
```

⚠️ **`rogueStealth` 是极少数不每帧重置的字段**。源码注释原文：
> `// rogueStealth doesn't reset every frame because it's a continuously building resource`

### 1.2 回复速率 ✅

```csharp
float currentStealthGen = UpdateStealthGenStats();
rogueStealth += rogueStealthMax * (currentStealthGen / 120f);   // 源码注释：120 frames = 2 seconds

private float UpdateStealthGenStats()
{
    // 源码注释：Stealth only regenerates at 1/3 speed while moving.
    bool standstill = Player.StandingStill(0.1f) && !Player.mount.Active;
    return standstill ? stealthGenStandstill
                      : stealthGenMoving * BalancingConstants.MovingStealthGenRatio * stealthAcceleration;
}
```

✅ **静止回满 = 120 帧 = 2 秒**（在 `stealthGen == 1` 时）。
⚠️ 源码注释写"移动时 1/3 速"，但常量 `MovingStealthGenRatio = 0.5f` 是 **1/2**，还要再乘一个 `stealthAcceleration`。**注释与代码不符，以 0.5f 为准。**

**骑乘时按"移动"处理**（`&& !Player.mount.Active`）——坐骑上永远吃不到静止回复。

其他修正来源：
```csharp
stealthGenStandstill += ShadowPotion.StealthRegenBoost;   // 暗影药水
stealthGenMoving     += ShadowPotion.StealthRegenBoost;
stealthGenStandstill += accStealthGenBoost;              // 饰品
stealthGenMoving     += accStealthGenBoost;
rogueStealth += 0.5f;                                     // 受击时（CalamityPlayerHitHurt.cs:2441）
```

### 1.3 触发门槛与消耗 ✅

```csharp
public bool StealthStrikeAvailable()
{
    if (rogueStealthMax <= 0f) return false;
    float consumptionMult = 1f;
    if      (stealthStrikeHalfCost) consumptionMult = 0.5f;
    else if (stealthStrike75Cost)   consumptionMult = 0.75f;
    else if (stealthStrike90Cost)   consumptionMult = 0.9f;
    return rogueStealth >= rogueStealthMax * consumptionMult;
}
```
⚠️ **潜伏攻击不需要满潜伏**。带减耗饰品时，**50% 潜伏就能触发**。源码注释也点明了这点：
> `// Sound plays upon hitting full stealth, not upon having stealth strike available (this can occur at lower than 100% stealth)`

消耗：
```csharp
public void ConsumeStealthByAttacking()
{
    stealthStrikeThisFrame = true;
    stealthAcceleration = 1f;                    // 攻击会重置加速度

    float lossReductionRatio = flatStealthLossReduction / (rogueStealthMax * 100f);
    float remainingStealth   = rogueStealthMax * lossReductionRatio;
    float stealthToLose      = rogueStealthMax - remainingStealth;
    if (stealthToLose < 0.01f) stealthToLose = 0.01f;    // 源码注释：不能少于一点

    if      (stealthStrikeHalfCost) rogueStealth -= 0.5f  * stealthToLose;
    else if (stealthStrike75Cost)   rogueStealth -= 0.75f * stealthToLose;
    else if (stealthStrike90Cost)   rogueStealth -= 0.9f  * stealthToLose;
    else                            rogueStealth  = remainingStealth;
}
```

**任何造成伤害的物品在使用的第一帧都会消耗潜伏**，不限于盗贼武器：
```csharp
Item it = Player.HeldItem;
bool hasDamage   = it.damage > 0;
bool hasHitboxes = !it.noMelee || it.shoot > ProjectileID.None;
bool isPickaxe   = it.pick > 0;
bool isAxe       = it.axe > 0;
```
源码注释解释了为什么：
> `// This doesn't trigger stealth strike effects (ConsumeStealthStrike instead of StealthStrike) so non-rogue weapons can't call lasers down from the sky and such.`
> `// Using any item which deals no damage or is a tool doesn't consume stealth.`

→ **镐子和斧头不消耗潜伏**（挖矿不会打断蓄势）。

### 1.4 伤害公式（本系统最精密的一处）⚠️

```csharp
double averagedStealthGen = 0.8 * stealthGenMoving + 0.2 * stealthGenStandstill;
double fakeStealthTime    = BalancingConstants.BaseStealthGenTime / averagedStealthGen;   // BaseStealthGenTime = 4f

int    realUseTime    = Math.Max(it.useTime, it.useAnimation);
double useTimeFactor  = 0.75 + 0.75 * Math.Log(realUseTime + 2D, 4D);          // 以 4 为底的对数

double stealthGenFactor = Math.Max(Math.Pow(fakeStealthTime, 2D / 3D), 1.5);   // 2/3 次幂，下限 1.5

double stealthAddedDamage = rogueStealth
                          * BalancingConstants.UniversalStealthStrikeDamageFactor   // = 0.42
                          * useTimeFactor
                          * stealthGenFactor;
```

**常量** ✅：
```csharp
public static double UniversalStealthStrikeDamageFactor = 0.42;
internal static readonly float BaseStealthGenTime   = 4f;      // 4 秒
internal static readonly float MovingStealthGenRatio = 0.5f;
```

**源码里自带两张对照表**（注释形式），直接抄录：

| 武器 `useTime` | 伤害倍率 |
|---:|---:|
| 3 | 162% |
| 8 | 200% |
| 13 | 221% |
| 17 | 234% |
| 20 | 242% |
| 30 | 263% |
| 59 | 297% |

| 潜伏蓄满耗时 | 伤害倍率 |
|---:|---:|
| 2.50 秒 | 184% |
| 4.00 秒 | 252% |
| 6.00 秒 | 330% |
| 9.00 秒 | 433% |

**两条设计意图，源码注释明说**：
> `// Lower stealth generation rate (especially while moving) enables higher maximum stealth damage.`
> `// This enables stealth to be conditionally useful -- even powerful -- even without a dedicated stealth build.`

即：**回复越慢 → 单次潜伏攻击越强**。这是一个自平衡设计——堆潜伏回复的 build 打得频繁但每下弱，不堆的 build 打得少但每下重。

⚠️ **`averagedStealthGen` 的权重是 0.8 移动 + 0.2 静止**，说明设计者假定玩家 80% 时间在移动。

**额外效果**：
```csharp
Player.aggro -= (int)(rogueStealth * 300f);      // 潜伏降低仇恨
```

### 1.5 视听反馈 ✅

```csharp
// 满潜伏时播一次音（不是可触发时）
if (playRogueStealthSound && rogueStealth >= rogueStealthMax && Player.whoAmI == Main.myPlayer)
{
    playRogueStealthSound = false;
    SoundEngine.PlaySound(RogueStealthSound, Player.Center);
}
else if (rogueStealth < rogueStealthMax)
    playRogueStealthSound = true;      // 掉下来就重新武装音效
```
**音效锚定"满"而非"可用"** —— 因为"满"是一个确定的、玩家能预期的时刻，而"可用"会随饰品变化。

脱下盗贼套装立即清零：
```csharp
if (!wearingRogueArmor) { rogueStealth = 0f; playRogueStealthSound = false; return; }
```

**玩家外观**：`CalamityPlayerDrawEffects.cs` 里按 `rogueStealth / rogueStealthMax` 降低玩家不透明度——**潜伏值就是玩家的透明度**。这是最直观的资源条，不需要 UI。

### 1.6 潜伏消耗的两种入口 ⚠️

源码区分了两个方法，**这是理解"为什么有些武器的潜伏是自动的、有些要手动"的关键**：

| 方法 | 触发者 | 效果 |
|---|---|---|
| `ConsumeStealthByAttacking()` | 引擎自动（任何伤害物品的第一帧） | **只扣潜伏，不触发潜伏效果** |
| 武器代码内手动调用 | 武器自己在 `Shoot` 里判 `StealthStrikeAvailable()` | 扣潜伏 **且** 走潜伏分支 |

→ **每把盗贼武器的"潜伏攻击"都是它自己在 `Shoot()` 里写的 `if` 分支**，不是引擎给的。这就是为什么 24 把武器的潜伏形态千差万别。

## 第二部分：24 把武器的潜伏形态分类

按"潜伏攻击相对常态改变了什么"归类，这比按职业列表更有用：

### A. 替换型（潜伏 = 完全不同的实体）
| 武器 | 常态 | 潜伏 |
|---|---|---|
| **Exorcism / 驱魔十字架** | 巨型圣十字：升起→坠落→钉住高频圣光→延迟大爆 | 旋转后追向光标，更强爆炸收尾 |
| **Whitewater / 激流瓶** | 瓶跟随光标，命中爆 **4** 支水矛并返回 | 固定 **6** 支水矛 + 回归后形成漩涡（治疗 5 秒 / 他人 10 秒） |
| **Leviathan Teeth / 利维坦之牙** | **2** 枚牙，钉住后 **2 秒**二次贯穿 | 玩家附近形成夹合巨颚 |
| **Urchin Stinger / 深渊海胆蛰** | **2** 根刺 | 只投 **1** 根，钉得更久；已有潜伏刺时再钉满 **7** 根 → 销毁全部并 **175%** 辐照爆 |

### B. 增强型（潜伏 = 同一实体的强化版）
| 武器 | 潜伏强化点 |
|---|---|
| **Blazing Star / 烈火之星** | 高速投掷 + 240 DPS 撕裂 5 秒 + 玩家周围大环形飞刃 |
| **Glaive / 回飞刃** | 同上，但撕裂降为 60 DPS |
| **Meteor Fist / 陨星拳套** | 立即加速、追踪更强、命中额外流星爆 |
| **Toxicant Twister / 剧毒旋风** | 更快更宽 + 额外追踪毒滴 |
| **Samsara Slicer / 回春环刃** | 滞留更久、放小环刃更频繁 + 20 护穿（**不增加数量**） |
| **Contaminated Bile / 污秽胆汁** | 辐照胆汁云 + 向上逸出硫磺泡 |
| **The Old Reaper / 死神遗镰** | 先上升→追光标→持续降酸雨 |
| **Sealed Singularity / 秘封奇点** | 更大更久的场（**不是第二个黑洞**） |

### C. 形态转换型（潜伏 = 已有实体重组）
| 武器 | 转换 |
|---|---|
| **Eclipse's Fall / 日蚀之陨** | 所有滞留碎片汇成黯化投矛（阈值 **20** 片） |
| **Vega / 织女星** | 标枪→滞留星 变为 天琴座星群持续打击 |
| **Shard of Antumbra / 半影裂片** | 额外放出 **9** 枚克隆标枪 |
| **Refraction Rotor / 衍曜旋刃** | 固定投出 **3** 枚会追踪的圆盘 |
| **Star of Destruction / 毁灭之星** | 跟随更快、可持续命中、期满爆更大 |

### D. 锚点型（潜伏 = 在目标上建立触发点）
| 武器 | 锚点效果 |
|---|---|
| **Profaned Partisan / 渎神投矛** | 钉住目标，后续标枪命中该目标转化出追踪圣火 |
| **Spear of Paleolith / 古岩投矛** | 钉住后，其他标枪命中同目标会碎成更多化石 |

### E. 无传统潜伏型（右键消耗满潜伏换取增益）⚠️
| 武器 | 机制 |
|---|---|
| **Molten Amputator / 熔岩切碎者** | 右键消耗满潜伏 → 强化接下来 **30** 次投掷：攻速 **3 倍**、飞更快，但**无法召回** |
| **Nanoblack Reaper / 纳米黑死神** | 右键消耗满潜伏 → 强化接下来 **30** 次投掷：攻速 **3 倍**、叠加斩击，但**不再雕刻** |

**这两把用了完全相同的"30 次 / 3 倍 / 失去核心能力"结构**，是 2.1 引入的新范式：潜伏不再是"一次强力攻击"，而是"一段强化窗口"。

### F. 危险蓄力型（潜伏靠按住蓄，过蓄会自伤）⚠️
| 武器 | 机制 |
|---|---|
| **Duststorm in a Bottle / 瓶中尘** | 按住蓄潜伏 → 瓶更早碎裂；**过蓄在手上爆炸并伤害玩家**；潜伏瓶连续泄出数个尘云 |
| **Sealed Singularity / 秘封奇点** | 同样的"按住蓄潜伏、更早释放、过蓄手上爆" |
| **Doomsday Device / 末日诡雷** | 左键蓄力；满蓄后 **18 帧**内出手不消耗潜伏，继续按住则快速耗尽 |

**这是 2.1 盗贼最激进的设计**：把"潜伏"从被动积累变成主动的、有风险的操作。

## 第三部分：Nanoblack Reaper 的 4 帧判定（全表最精密的时机窗口）

官方原文："在它刚开始回归的**精确 4 帧**内松手，会以光速雕刻离光标最近目标；同为 **150 护甲穿透**，额外 **+100% 暴击**并可超级暴击。"

**与第 1 篇 Starfleet 的 7 帧完美窗口对照**：

| | Starfleet | Nanoblack Reaper |
|---|---:|---:|
| 窗口 | **7 帧**（`23 ± 3`） | **4 帧** |
| 提示方式 | 枪前推动画走 `Pow(..., 8)` 曲线，最后 2 帧暴冲 | 镰刃"刚开始回归"的转折点 |
| 失败惩罚 | 散布从 3.4° 炸到 51.6° | 无雕刻（但保留常规伤害） |
| 成功奖励 | 伤害 ×1.75、弹速 ×3 | 光速雕刻 + 150 AP + 100% 暴击率 |

**4 帧 = 0.067 秒**，比 Starfleet 严格近一倍。它可行的原因是**判定点绑在一个物理事件上**（镰刃由外飞转为回归的瞬间），玩家能从运动方向的翻转预判，而不是靠记忆一个抽象的计时。

> **可复刻要点**：极短的时机窗口**必须锚定在一个可见的物理转折点上**（速度反向、动画定格、颜色突变），不能靠纯计时。Starfleet 用 8 次方曲线人为造了一个"暴冲"转折点，Nanoblack Reaper 直接用了回归转折——两者都是同一个思路。
