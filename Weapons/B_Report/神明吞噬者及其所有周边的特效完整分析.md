## 一、DoG 视觉语言核心体系

### 1.1 双色主题调色板

DoG 的一切特效都围绕三个核心颜色运转，缺一不可：

| 颜色名 | 近似值 | 用途场景 |
|---|---|---|
| **Cyan（青色）** | `Color.Cyan` / `DoGLightBlue` | 被动状态、普通攻击、退场色 |
| **Fuchsia（洋红）** | `Color.Fuchsia` / `Color.Magenta` | 主动攻击、激光墙、高危警告 |
| **DoGTwilight（紫）** | 介于两者之间的紫 | 传送、激光墙/阶段过渡、特殊状态 |

**动态变色公式（来自 `DevourerofGodsHead.cs line 49`）：**
```csharp
public static Color SpecialMoveColor =>
    Color.Lerp(Color.Fuchsia, Color.Cyan,
        MathHelper.SmoothStep(0, 1,
            (MathF.Sin(Main.GlobalTimeWrappedHourly * 2) + 1) * 0.5f));
```
——这是整个 DoG 视觉体系的"灵魂"：颜色本身是活的，在青与洋红之间平滑震荡。**任何想制造 DoG 感的武器，都应该用这个公式驱动主色。**

### 1.2 双层 Glowmask（发光叠层）

DoG 本体（头、身、尾、P2 形态）全部使用**双套 glowmask** 绘制：
- 一套青色 (`_Glow_Cyan.png`)
- 一套紫色 (`_Glow_Purple.png`)
- 传送冲刺后下颚额外叠加 `GodSlayerDashJaw`：大号洋红层 + 小号青色层，使用 `additive blend`

代码参考：`DevourerofGodsHead.cs line 2517, 2533`

**可用结论：** 武器的主弹幕贴图应该有青/紫两套叠层，用 additive 混合叠在原色之上，而不是只用一种颜色。

### 1.3 Primitive Trail（基元轨迹）

DoG 所有运动体都使用 **primitive trail 而非 dust trail**：
- 外层：`ScarletDevilStreak` shader（宽发光条）
- 内核：`SylvestaffStreak` shader（窄亮芯）
- 着色器：`ImpFlameTrail`
- 参考：`DoGFire.cs line 118`

被动火球 → 偏青色 trail  
传送扩散火球 → 偏紫/洋红 trail

**可用结论：** 刀刃、链条的轨迹效果应该用这个双层结构：外层是宽且淡的 DoG-Cyan，内核是极细极亮的 Fuchsia 或白色。

## 二、DoG Boss 本体特效详解

### 2.1 召唤与出场

- `CosmicWorm.cs`：召唤物在玩家上方约 **1600 像素**处生成 Boss
- 播放 `DevourerSpawn.ogg` 音效
- 触发开场台词对话系统（`DevourerofGodsHead.cs line 307`）

**可用：** 大招前的 "降临" 演出——从玩家上方某个位置向下冲的预兆特效。

### 2.2 战斗背景系统（`DoGBackgroundScene` + `DoGSky`）

只要 DoG 存活，背景系统全量激活：

**DoGSky 生成的裂隙结构：**
- 3 个**玻璃裂纹**
- 14 条**主裂隙臂**
- 12–16 条**外围裂缝**

**绘制顺序（`DoGSky.cs line 224`）：**
1. 风
2. 滚动雾
3. 裂隙光环
4. 现实裂纹
5. 扭曲裂隙本体

**天空颜色随状态变（`DoGSky.cs line 444`）：**
- 攻击态 → 洋红
- 被动态 → 青色
- 激光墙/传送/转阶段 → 紫色

**DoGVisualsManager 额外职责：**
- 暗化太阳/月亮
- 改变世界光照
- 用 render target 给裂隙内部和前景 **distortion metaball** 准备内容

**可用：** 大招激活期间可以参考这套"裂隙+颜色切换"的思路，在武器场周围制造少量裂纹 particle 和颜色变化。

### 2.3 传送裂隙（`DoGTeleportRift.cs`）

这是 DoG 特效中最值得学习的单品之一，完整流程：

**蓄力阶段（`DoGTeleportRift.cs line 80`）：**
- 画**星芒**（光芒四射形）
- 画**玻璃裂纹**（向外辐射的线段）
- 内缩 **bloom ring**（从外向内收缩的光晕环）
- 持续放 **SparkParticle**（火花）
- 持续放 **SquishyLightParticle**（软光粒子）
- 持续屏幕震动

**爆开瞬间（`DoGTeleportRift.cs line 158`）：**
- 生成 **25 条 DoGRiftCrack**（25 条辐射状现实裂缝）
- 大量**方形** distortion metaball
- 大量**圆形** distortion metaball
- SparkParticle 爆发
- 光粒子爆发
- **plasma pulse**（等离子脉冲）
- **shine explosion**（光芒爆炸）
- **StrongBloom**（强烈光晕）
- **最强屏幕震动**

**可用：** QuickDraw 的起手和收手、右键切换的模式过渡、大招起手，都可以完整借用这套流程。

### 2.4 DoGFire 火球（`DoGFire.cs`）

- **本体是 invisible projectile**（无贴图的弹幕）
- 真正的画面效果完全由 **primitive trail** 构成
- 被动：偏青色 trail
- 传送后扩散版：偏紫/洋红 trail
- 发射前：嘴部冒 `HeavySmokeParticle` + `SquishyLightParticle`

**可用：** 武器发射的弹幕不需要贴图，用 primitive trail 构造出火焰感即可。主弹幕颜色应跟当前模式或状态挂钩（被动青，主动洋红）。

### 2.5 DoGP1EndPortal / DoGPortal Shader

一阶段结束时飞入的传送门：
- 使用 **DoGPortal shader**
- 把 **Voronoi 噪声**旋成青/洋红旋涡（`DoGP1EndPortal.cs line 62`）

**可用：** 右键切换模式时的过渡动画——一个用 Voronoi 噪声构造的小型旋涡传送门在玩家附近开合。（参考 StreamGougePortal 的实现方式，叠青+洋红+黑三层旋转纹理）

### 2.6 激光墙系统（`DoGLaserWalls.cs` + `DoGLaserWallsBigBeam.cs`）

**DoGLaserWalls 线阵：**
- 先低透明预警（约 30 tick）
- 然后全力攻击
- 颜色：青 → 洋红渐变
- 类型 0–5：网格/斜线/交叉阵
- 类型 6：圆环激光墙

**DoGLaserWallsBigBeam 大激光：**
- 从屏外向玩家方向扫
- 开火时屏幕震动
- 颜色：洋红 → 青

**可用：** 大招的终结效果——从四面八方向目标收拢的激光墙线阵，先青色预警，然后洋红爆发。

### 2.7 咬合近战（`DevourerofGodsHead.cs line 2081`）

近身咬合瞬间：
- 生成 **20 个 SparkParticle**
- 屏幕震动
- 特殊命中音效
- 上下颚开合动画

**可用：** 链条/鞭形命中时的重型打击特效。

### 2.8 死亡动画（`DevourerofGodsHead.cs line 2332`）

- 血条关闭
- 逐段销毁身体，每段爆 **BoneTorch dust + gore**
- 最终 `DoGDeathBoom`：180 tick，半径 **4200**，青到洋红，**最高 28 强度震屏**
- **Dissolve shader**：以噪声阈值逐渐溶解，边缘用 `SpecialMoveColor` 着色

**可用：** 大招结束/消散的演出可以借用 Dissolve 边缘颜色变化的思路。

- 发射音效 `SoundID.Item92`

**可用程度：** ⭐⭐⭐⭐  
**可借鉴点：**  
- **双管扇形尘雾发射**：替换颜色为 Cyan + Fuchsia，制造 DoG 能量喷发感

### 3.9 StreamGouge（湍流凿）
**类型：** 近战（长矛）  
**特效记录（`StreamGougePortal.cs`）：**

**命中时特效（极其丰富）：**
- `ImpactParticle`：青白渐变颜色的冲击粒子
- `StreamGougeMetaball`：**20 个流体元球粒子**从目标位置扩散（圆形流体渲染）
  - 半径 60–64 的大号元球
  - 半径 24 的小号元球
  - 垂直穿刺方向排列成柱状
- 命中音效 `SoundID.Item74`

**传送门弹幕绘制（`StreamGougePortal.cs PreDraw`）：**
- **三层叠加旋转纹理**（用同一张 `StreamGougePortal.png`）：
  1. 黑色层（`Color.Black * 55%`）：正向旋转 `time * 6f`，缩放 1.2
  2. 青色层（`Color.Cyan * 55%`）：正向旋转 × 0.6，缩放 1.2
  3. 洋红层（`Color.Fuchsia * 55%`）：反向旋转 × 0.7，缩放 1.2
- 传送门中心额外绘制矛贴图（发光，以 `identity % 10f / 40f + 0.67f` 色相偏移）
- 传送门 `localAI[0]` 控制只在首次播放 `SwiftSlice` 音效
- 矛的伸出动画（`spearOutwardness` 从 4 到 52）

**可用程度：** ⭐⭐⭐⭐⭐  
**可借鉴点：**  
- **三层旋转叠加传送门** = DoG 传送门的平替实现（不需要写 shader，只用旋转贴图叠加）
- 青/洋红/黑三层正好与 DoG 主题完全一致
- **Metaball 流体效果**：可以给武器的重击加上这种效果

### 3.10 ThreadOfEradication（抹杀之弦）
**类型：** 远程（弓）  
**特效记录：**
- **蓄力激光墙系统**：
  - 按住攻击键 → itemTime 强制延长到 180（3秒 channel）
  - 松手瞬间（`itemTime == 1`，非 channel）：从玩家右侧 **2016 像素**处发射 `FriendlyLaserWallBeam`（穿越全屏！）
  - 若 channel 蓄力到 60 tick → 发射 **4x 缩放**的超大激光墙 + **5 强度屏幕震动**
  - 武器旋转实时跟随鼠标方向（±0.045 rad/tick 角速度限制）
- 屏幕震动：
  - 正常发射：2 强度
  - 充能发射：5 强度
- `FriendlyLaserWallBeam`：一条从屏外飞来的全屏激光线（DoG 激光墙同款）

**可用程度：** ⭐⭐⭐⭐⭐  
**可借鉴点：**  
- **大招的激光墙机制**：蓄力后从四个方向同时发射 FriendlyLaserWallBeam，向目标收拢
- **武器旋转跟随鼠标的角速度限制**：这个实现让武器有"惯性感"，适合用在大招的准备阶段
- 4x 缩放超大激光是大招高潮的绝佳呈现

### 3.12 HyperdeathRiftScepter（极死裂隙法杖）

  - 宽度由 `laserFX × sin(time*4/π)` 动态脉动

**可用程度：** ⭐⭐⭐⭐⭐

### 3.13 DimensionTearingDisk（次元撕裂圆盘）

### 3.14 FourSeasonsGalaxia（四季迦勒底）
**类型：** 近战（剑，多形态右键切换）  
**特效记录（这一部分最关键，用于右键切换参考）：**

**右键切换机制（`FourSeasonsGalaxia.cs line 217`）：**
```csharp
if (player.Calamity().mouseRight && CanUseItem(player) && player.whoAmI == Main.myPlayer)
{
    // 防止重复生成
    if (Main.projectile.Any(n => n.active &&
        n.type == ProjectileType<GalaxiaHoldout>() &&
        n.owner == player.whoAmI))
        return;

    Projectile.NewProjectile(source, player.Top, Vector2.Zero,
        ProjectileType<GalaxiaHoldout>(), 0, 0, player.whoAmI,
        0, Math.Sign(player.position.X - Main.MouseWorld.X));
}
```

**GalaxiaHoldout 的视觉职责：**
- 右键按下 → 在玩家正上方生成一把"幽影刃"（`GalaxiaHoldout`，0伤害）
- 这把幽影刃是纯视觉弹幕，用于展示"切换中"的动态过渡
- 完成切换 → 幽影刃消失，物品的 `mainAttunement` 替换

**武器贴图随形态变化：**
- Phoenix/Aries → `GalaxiaDawn.png`（暖色刃）+ `GalaxiaDawnOutline.png`
- Polaris/Andromeda → `GalaxiaDusk.png`（冷色刃）+ `GalaxiaDuskOutline.png`
- 两种贴图都有 7 帧动画（128px × 7 = 总高 896px）
- 实时动画：`currentFrame = (int)(GlobalTimeWrappedHourly * 15f) % 7`
- 分别用 `BlendState.NonPremultiplied`（外框 outline）+ `BlendState.Deferred`（主色）两层绘制

**可用程度：** ⭐⭐⭐⭐⭐（右键切换参考极佳）  
**可借鉴点：**  
- **右键切换时生成一个纯视觉幽影弹幕** = 给 CosmicDischarge 的模式切换提供视觉反馈
- **武器贴图随形态变化** + 帧动画 = CosmicDischarge 可以有三套不同风格的发光外框
- **在玩家 Top 生成弹幕的定位** = 切换演出弹幕的标准位置
- **防重复检测（already has holdout → return）** = 防止切换连按穿透的标准写法
