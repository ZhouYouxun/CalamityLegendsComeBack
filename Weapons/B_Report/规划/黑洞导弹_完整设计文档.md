# 黑洞导弹（Black Hole Missile）完整设计文档

> 状态：已定稿，作为实现规格使用。  
> 对应 Boss：无尽虚空（Ceaseless Void）。  
> 武器定位：消耗火箭/手榴弹的远程传奇火箭筒；单体锁定、弹药形态分化、失控黑洞与全屏弹幕汇聚。  
> 本文中的帧数以 `60 帧 = 1 秒` 计。数值均为第一版平衡目标；实现时不得自行替换为“约等于”的模糊值。

---

## 1. 一句话定义与设计边界

**黑洞导弹是一把“每次装填都改变攻击规则”的单体传奇火箭筒：左键根据弹药变形，右键养成并引爆一颗逐渐失控的黑洞，被动以黑线锁定高价值敌人，大招把全屏可转向的我方弹幕汇入一个三倍易伤的目标。**

它不是铺设地雷、裂隙或锚点后再引爆的武器。该循环与现有 SS 的“持续架枪—建立场面—兑现”的体验过近，必须避免。

实现必须遵守以下边界：

1. 左键每发都立即开火；没有任何左键蓄力、连发或预置物。
2. 左键的 45 帧射击间隔、后坐力和手臂缓慢复位是武器重量感的一部分，不能用攻速配装无限缩短。攻速只影响复位动画的后半段，实际最低间隔锁定为 30 帧。
3. 右键不消耗弹药，也不读取当前装填的火箭类型；它始终是一颗标准黑洞。
4. 右键满级后才允许发射“超重型黑洞导弹”。提前松开只能让黑洞塌缩，不能偷取终结伤害。
5. 被动的 1.25 倍增伤作用于**任何来源**的伤害，而非仅本武器；多人时不叠加。
6. 大招采用本文的“方案一：终末吸积”。方案二完整保留在文末，明确标为废案，不进入第一版实现。

## 2. 获取、基础物品和共用规则

### 2.1 获取与配方入口

| 项目 | 规格 |
|---|---|
| 物品内部名 | `BlackHoleMissile` |
| 归属目录 | `Weapons/BlackHoleMissile/` |
| 稀有度 | 与无尽虚空同阶段的传奇稀有度；第一版使用 `Turquoise`，不使用开发者稀有度。 |
| 默认获取 | 加入 `BossRelicWeaponRecipes` 的 `CeaselessVoidRelic` 映射；开启“Boss 遗物配方”配置后，可由无尽虚空遗物直接合成。 |
| 首次掉落 | 不新增普通掉落池；若后续要接入传奇补给箱，补给箱只给本体，不给配饰。 |
| 合成站 | 遗物配方沿用现有自动配方逻辑；配饰使用远古操纵机。 |

### 2.2 本体数值

| 属性 | 数值/规则 |
|---|---|
| 伤害 | `420`，`DamageClass.Ranged`。所有后文百分比均以最终武器伤害为基准。 |
| 暴击 | `14%`。 |
| 击退 | `7.0`。 |
| 左键基础间隔 | `45` 帧；集束火箭专属间隔为 `75` 帧。 |

| 右键 | 引导型，最多同时存在一颗黑洞。 |
| 弹药 | 火箭类弹药 + 白名单中的困难模式前手榴弹。每次左键成功开火消耗 1 个弹药。 |
| 地形 | 本体不主动破坏物块；火箭 II、IV 仅继承原弹药本来拥有的破块能力，仍受服务器“环境伤害”设置约束。 |
| 持有判定 | 只有当前手持本体时，被动黑线、右键黑洞、大招蓄力与相关配饰效果才会运行。切换武器会立即结束右键和大招蓄力。 |

### 2.3 弹药选择器

黑洞导弹不能仅依赖 `Item.useAmmo = AmmoID.Rocket`，因为手榴弹不是原生火箭弹药。必须实现专用弹药选择器。

选择顺序如下：

1. 先按 Terraria 原生弹药槽、背包的检索顺序寻找火箭类弹药；
2. 若玩家在更靠前的有效槽位放置了本武器允许的手榴弹，则该手榴弹优先于后续槽位的火箭；玩家可借此通过弹药槽顺序主动切换弹药；
3. 合法火箭为所有 `ammo == AmmoID.Rocket` 的弹药；
4. 合法手榴弹仅限原版困难模式前的标准手榴弹族：普通、黏性、弹跳和庆典手榴弹。它们在本武器中统一进入“手榴弹形态”，不继承黏附、弹跳或庆典的额外原版行为；
5. 蜜蜂手榴弹、圣手榴弹、模组自定义投掷爆炸物、非 `AmmoID.Rocket` 的其他消耗品均不接受，除非未来显式加入白名单；
6. 没有合法弹药时，左键不启动后坐动画、不产生空弹音效、不消耗弹药；右键和大招不受此限制。

所有自定义弹幕必须通过被选择弹药的伤害、暴击和初速度计算初始参数。后续派生弹幕不再次消耗弹药，也不再次读取弹药伤害。

## 3. 左键：即时发射、重后坐与四类装填形态

### 3.1 通用时序与动画

左键按下即生成一枚主弹，枪口不得存在蓄力等待。

| 时间 | 表现与规则 |
|---|---|
| `0` 帧 | 读取并消耗 1 个合法弹药；主弹从枪口生成；播放重型发射音和强枪口闪光。 |
| `0–8` 帧 | 炮身与手臂向后抬起；玩家获得反向 `6.5 px/帧` 的视觉后坐力，实际位移乘以 `0.35`，不能借此无限位移。 |
| `8–45` 帧 | 手臂、炮身以缓出曲线缓慢降回瞄准位置；左键锁定，不能提前开下一发。 |
| `45` 帧 | 复位完成，允许下一发。 |

后坐力方向严格取枪口朝向的反方向。玩家在空中时后坐力可略微改变位置，但不得重置飞行时间、翅膀时间或冲刺状态。

### 3.2 共用标记：导引锁定

火箭 I–IV 的主弹直击有效目标后施加 **导引锁定**，持续 `240` 帧（4 秒）。

* 导引锁定是左键短时标记；其作用是为背部导弹指定绝对追踪目标。
* 同一玩家只保留一个导引锁定。新直击会立刻覆盖旧目标。
* 目标死亡、无敌、失活、离开世界或与玩家距离超过 `6000 px` 时立即清除。
* 导引锁定与右键产生的“虚空烙印”、被动产生的“牵引烙印”是三个独立系统，名称和功能不得混用。

### 3.3 手榴弹形态：重力裂子弹

**目的：** 让困难模式前廉价弹药可用，形成小范围精确分裂追击，而不是低配火箭。

| 项目 | 数值与实现 |
|---|---|
| 主弹 | `黑洞手榴弹`；初速度 `21 px/帧`，不制导，始终受重力，竖直速度每帧 `+0.22`，最大下落速度 `18 px/帧`。 |
| 碰撞 | 命中敌人或物块立即爆炸；爆炸半径 `72 px`，伤害为武器伤害的 `100%`。 |
| 目标记录 | 若主弹先命中有效敌人，记录该 NPC 为“裂子目标”；命中地形时无记录。 |
| 一级裂子 | 爆炸生成 `5` 枚，伤害各为 `24%`，持续 `90` 帧。若存在裂子目标，全部以中等转向速度追踪该目标；否则追踪爆点附近 `800 px` 内最近有效敌人。 |
| 二级裂子 | 每枚一级裂子首次命中时最多生成 `2` 枚，伤害各为 `12%`，持续 `45` 帧，只能命中一次。 |
| 命中限制 | 一级、二级裂子对同一 NPC 的本地无敌帧分别为 `12`、`18` 帧；不能借贴脸多段无限叠伤。 |
| 视觉 | 主弹由小黑洞、紫黑引力丝和可见的手榴弹弹体构成；裂子应像被撕出的黑色碎片，不使用普通爆炸火焰。 |

### 3.4 火箭 I–IV：黑洞制导弹

**目的：** 这是单体最稳定的主力装填。I–IV 的攻击脚本必须相同，差异仅来自原火箭爆炸范围和原版破块能力。

| 项目 | 数值与实现 |
|---|---|
| 主弹 | `黑洞制导火箭`；初速度取弹药速度与 `38 px/帧` 中较大者，最高 `46 px/帧`。 |
| 制导 | 发射前 `9` 帧保持直线；之后每帧最多转向 `4.5°`，优先追踪鼠标附近 `900 px` 内的有效敌人，找不到则直线飞行。 |
| 直击 | 命中有效敌人造成 `110%` 伤害，半径继承原火箭对应的爆炸半径；立即施加导引锁定。 |
| 背部齐射 | 直击后的第 `8`、`14`、`20` 帧，分别从玩家背后偏左、正后、偏右的位置射出 1 枚 `黑洞追击导弹`，共 3 枚。 |
| 追击导弹 | 每枚伤害 `38%`，初速度 `18 px/帧`，转向上限 `9°/帧`，无视物块，最多存活 `150` 帧；只追踪当前导引锁定目标。 |
| 同体限制 | 三枚追击导弹对同一 NPC 的本地无敌帧为 `9` 帧，发射时序已错开，允许依次命中。 |
| 空射 | 主弹未直击敌人时不生成背部齐射；不能把空射变成免费自动索敌。 |

### 3.5 集束火箭：三级递归碎裂

**目的：** 放弃单体制导，换取高速度、混乱覆盖和不可预测的延时爆炸。它是清屏/大体积目标弹药，不是稳定 Boss 单体最优解。

| 项目 | 数值与实现 |
|---|---|
| 射速代价 | 左键间隔固定为 `75` 帧；所有攻速修正后最低为 `60` 帧。 |
| 主弹 | `递归黑洞火箭`；初速度 `56 px/帧`，不制导，碰撞半径仅 `48 px`，伤害 `95%`。 |
| 一级碎片 | 主弹爆炸时生成 `6` 枚，伤害各 `26%`，随机扇形方向，持续 `60` 帧。 |
| 二级碎片 | 每枚一级碎片死亡时生成 `3` 枚，伤害各 `16%`，持续 `48` 帧。 |
| 三级碎片 | 每枚二级碎片死亡时生成 `2` 枚，伤害各 `10%`，不再生成后续弹幕；在 `18–54` 帧随机延迟后爆炸。 |
| 数量上限 | 单发理论总数为主弹 `1` + 一级 `6` + 二级 `18` + 三级 `36` = `61` 个；这是硬上限，任何异常情况下不得额外递归。 |
| 命中限制 | 一级/二级/三级对同一 NPC 的本地无敌帧为 `15/18/24` 帧；三级只有爆炸判定，无直接碰撞判定。 |
| 视觉 | 每一级尺寸依次缩小、黑洞核心变淡；三级仅保留黑色裂点与短促紫色脉冲，以提示随机延时爆炸。 |

### 3.6 迷你核弹 I–II：天顶坠落

**目的：** 用“先上天、后锁定、再坠落”的攻击语言区别于普通直射火箭。无目标时转为固定位置的低强度控场黑洞。

| 项目 | 数值与实现 |
|---|---|
| 初始发射 | 无视鼠标方向，始终以 `Vector2.UnitY * -24` 向上发射；前 `42` 帧不寻找目标。 |
| 选取时机 | 第 `42` 帧时，在鼠标世界坐标 `1200 px` 内寻找最近的有效敌人；同距离时优先选择有牵引烙印、虚空烙印或导引锁定的敌人。 |
| 有目标 | 核弹转为下坠冲刺，速度在 `18` 帧内提升至 `60 px/帧`，每帧最大转向 `8°`，无视物块。命中时爆炸。 |
| 无目标 | 核弹飞至鼠标位置上方 `200 px` 后停留并塌缩为“小型静滞黑洞”；持续 `150` 帧，半径 `110 px`，每 `20` 帧造成 `28%` 伤害。 |
| 小怪牵引 | 静滞黑洞仅拉动非 Boss、非事件核心、质量正常的敌怪；牵引速度上限 `5 px/帧`。Boss、蠕虫段、无敌目标不受位移影响，但可受伤。 |
| 核弹 I | 命中爆炸半径 `180 px`，伤害 `180%`。 |
| 核弹 II | 命中爆炸半径 `260 px`，伤害 `240%`。 |
| 安全限制 | 坠落核弹和静滞黑洞都不破坏物块、不触发普通火箭的地形伤害。 |

## 4. 右键：失控奇点与超重型黑洞导弹

### 4.1 右键的目标

右键是无消耗、可持续引导的战场控制与爆发工具。它不读弹药、不生成左键分支效果；它的风险来自黑洞会越来越不受鼠标控制，并强制玩家放弃左键输出。

### 4.2 引导状态机

| 阶段 | 帧数 | 黑洞行为 |
|---|---:|---|
| 诞生 | `0–59` | 在鼠标处生成，半径从 `28` 增至 `70 px`；以 `0.18` 的插值系数跟随鼠标；每 `30` 帧伤害一次，伤害为 `18%`。 |
| 增殖 | `60–179` | 半径从 `70` 增至 `180 px`；鼠标跟随降至 `0.055`；开始主动向 `1200 px` 内最近有效敌人偏移；每 `20` 帧伤害一次，伤害从 `26%` 线性升至 `45%`。 |
| 满级/失控 | `180` 起 | 半径固定 `180 px`，伤害固定每 `20` 帧 `45%`，不再成长；鼠标跟随仅 `0.018`，对最近高价值目标的追逐系数为 `0.070`。 |

右键引导期间：

* 玩家可以移动、跳跃、飞行，但不能左键、不能切换物品、不能开始大招；
* 每名玩家仅能拥有一颗本武器的右键黑洞；再次右键不会生成第二颗；
* 黑洞不吸拉 Boss、蠕虫段、无敌敌人或事件核心；对普通敌怪的牵引速度上限为 `7 px/帧`；
* 黑洞触碰有效敌人时施加 **虚空烙印**。烙印在该 NPC 死亡、失活或 despawn 前永久存在，不会自然倒计时；玩家死亡或离开世界时清除其施加的全部烙印；
* 虚空烙印不直接提供伤害倍率。它用于左键核弹的选取优先级、终末吸积的目标资格和视觉辨识；
* 黑洞对单个 NPC 的本地无敌帧为 `20` 帧，不能用巨大体型一帧内重复多段。

### 4.3 满级提示与释放

到达 `180` 帧时，必须同时播放独立的“就绪”音效、在炮口和黑洞之间闪过一条白紫色引力线，并给玩家 HUD 一个 `0.5 秒` 的“导弹就绪”脉冲。没有这些提示，玩家无法可靠判断何时该松键。

| 松开时机 | 结果 |
|---|---|
| 未满级（< 180 帧） | 黑洞在 `18` 帧内自行塌缩，造成最后一次 `35%` 小爆炸；不发射导弹，不消耗弹药。 |
| 满级（>= 180 帧） | 从火箭筒枪口立即发射 `超重型黑洞导弹`。 |

超重型黑洞导弹规格：

* 初速度 `78 px/帧`，无视物块，始终追踪黑洞当前中心，而不是重新寻找敌人；
* 到达中心后与黑洞同时湮灭，爆炸半径 `420 px`；
* 湮灭本体伤害 `460%`，黑洞最后一跳伤害不重复计算；
* 被虚空烙印的敌人在湮灭中额外承受 `+35%` 本次伤害；
* 爆炸后进入 `90` 帧“空间湍流”，此期间不能再次右键；这是防止无弹药无限爆发的唯一右键冷却。

## 5. 被动：奇点牵引律

### 5.1 功能定义

手持黑洞导弹时，玩家与一个“当前牵引目标”之间始终绘制一根细黑线。黑线是纯视觉和目标选择载体，不造成触碰伤害；被黑线选中的目标获得 **牵引烙印**。

牵引烙印效果：

* 目标受到的**所有最终伤害**乘以 `1.25`；
* 包括任意玩家的近战、远程、魔法、召唤、哨兵、持续伤害、减益伤害和本武器伤害；
* 多名玩家同时用黑洞导弹牵引同一目标时，倍率仍然只有 `1.25`，绝不叠乘；
* 黑线切换到另一个目标后，旧目标的牵引烙印立即移除；它不是永久标记；
* 牵引烙印可与右键虚空烙印共存；二者图标和颜色必须不同。

### 5.2 有效目标判定

以下对象不能成为黑线目标，也不能被施加牵引烙印：

* `inactive`、友方、城镇 NPC、不可追击目标；
* 当前 `dontTakeDamage`、`immortal` 或任何已被模组判定为无敌的目标；
* 世纪之花钩爪、猪龙鱼公爵切换阶段时的无敌本体、月球领主尚未开启的心脏，以及同类“存在但不可受伤”的 Boss 部件；
* 蠕虫类 Boss 的中间身体段。

蠕虫类 Boss 的头部和尾部允许被选取、允许被烙印；中间身体段必须被 `WormSegmentClassification` 排除。不能只通过 `realLife >= 0` 粗暴排除，否则会错误排掉头尾。

### 5.3 目标优先级与切换

每 `6` 帧检查一次；当前目标死亡、失活、转为无敌或不可追击时必须**当帧**重选，不能等待下一轮计时。

候选目标按以下顺序选择：

1. `5000 px` 内任何有效 Boss；即使近处有大量小怪，也始终优先 Boss。多个 Boss 同时存在时取距离玩家最近的一个；
2. 没有 Boss 时，选择 `3000 px` 内生命上限 `>= 5000` 的有效精英敌怪，取距离最近者；
3. 仍无目标时，选择 `1800 px` 内最近的普通有效敌怪；
4. 没有候选时，黑线淡出，不保留上一目标的烙印。

黑线端点固定在目标碰撞箱中心。线宽 `2 px`，中心纯黑、外缘深紫，透明度在 `0.45–0.85` 间缓慢脉动。目标切换时以 `6` 帧完成拉伸，不允许瞬移闪屏。

### 5.4 多人同步

* 牵引目标由持有者客户端请求、服务器验证并同步目标 NPC 索引；
* `TetheredByBlackHoleMissileCount` 计数由全局 NPC 状态维护；计数大于零时只施加一次 `×1.25`；
* 客户端仅绘制本地玩家的黑线；其他玩家的黑线可绘制为半透明版本，但不得影响判定；
* 目标失效、玩家死亡、物品不再手持时，服务器负责清理对应拥有者的计数，避免残留易伤。

## 6. 传奇能量与大招（采用方案一）

### 6.1 能量规则

传奇能量上限为 `100`，只在手持黑洞导弹时显示独立 HUD。

| 行为 | 能量获得 | 限制 |
|---|---:|---|
| 左键主弹直击 | `+4` | 每个左键主弹最多一次。 |
| 左键派生弹命中 | `+1` | 每次左键最多获得 `+2`，集束递归不能刷能量。 |
| 右键黑洞伤害 | `+1` | 每 `30` 帧最多一次，不按命中敌人数叠加。 |
| 被牵引烙印目标受到任意伤害 | `+1` | 每 `15` 帧最多一次；可由队友触发。 |

能量满时播放一次就绪音效。若传奇技能未施放，能量不会自然衰减。

### 6.2 大招名称：终末吸积

选择理由：该方案直接兑现“黑洞导弹”的核心——把目标变成一个会吞没我方火力的微型黑洞。它与左键装填、右键失控黑洞和被动高价值锁定均有直接关联，并且相比方案二不需要篡改未知敌方弹幕的行为。

#### 第一段：蓄力

| 项目 | 规则 |
|---|---|
| 启动 | 传奇能量满、玩家手持本体且不存在右键黑洞时，按传奇技能键。 |
| 时长 | `180` 帧（3 秒）。 |
| 动画 | 炮口处凝聚黑洞核心，粒子由黑转紫再转白；炮身轻微后仰，不旋转。 |
| 行动限制 | 蓄力期间可移动，移动速度乘以 `0.80`；不能攻击、右键、切换物品或再次启动技能。 |
| 中断 | 死亡、眩晕、缴械、切换物品、手持状态丢失时取消；返还 `50` 点能量。 |
| 完成 | 消耗 `100` 点能量，进入“终末导弹待发”状态，持续 `360` 帧（6 秒）；HUD 以白紫高亮提示“左键发射”。 |
| 超时 | 待发状态超时则自动熄灭，不返还能量；防止玩家永久保存一发全屏大招。 |

#### 第二段：左键发射

待发期间按左键，不读取、不消耗任何火箭/手榴弹，而是发射 `终末黑洞导弹`。

* 目标选择：优先被动黑线的当前 Boss；没有则依照被动相同优先级寻找最高价值有效目标；没有目标时不给发射，保留待发状态；
* 导弹速度 `52 px/帧`，强追踪，每帧最大转向 `12°`，无视物块；
* 命中目标时先造成 `180%` 直接伤害，然后在该目标中心建立“终末吸积核”；
* 若导弹目标在飞行中失效，立即重新寻找同优先级目标；无候选时导弹在 `30` 帧内消散，不退还能量；
* 终末导弹的视觉必须明显大于普通右键导弹，但颜色偏白紫，避免和右键黑紫湮灭导弹混淆。

#### 第三段：五秒吸积窗口

终末吸积核持续 `300` 帧（5 秒）。建立时播放一次全屏向中心收缩的冲击波，冲击波只做视觉，不伤害、不推拉玩家。

| 效果 | 精确定义 |
|---|---|
| 目标易伤 | 吸积核附着目标受到的所有最终伤害乘以 `3.00`。若它同时是被动牵引目标，则先应用牵引烙印，再应用终末吸积，最终为 `1.25 × 3.00 = 3.75`。 |
| 项目吸积 | 每 `30` 帧扫描一次激活玩家当前屏幕内的可吸积我方弹幕；首次被选中后标记为“已吸积”，本次大招内不重复扫描。 |
| 弹幕轨迹 | 已吸积弹幕维持原伤害、暴击和拥有者，获得 `90` 帧生存时间；速度每帧向吸积核中心插值 `0.18`，最高速度 `54 px/帧`；无视物块。抵达目标后按原弹幕正常命中并消失。 |
| 可吸积弹幕 | 仅限有伤害、`friendly == true`、`hostile == false`、自由飞行且未被标记为持握物/光束/钩爪/宠物/坐骑/哨兵/召唤物本体的弹幕。不能强制改写持续激光、鞭、炮台、随从、玩家持握弹幕或其他模组的专有控制弹幕。 |
| 多人 | 扫描所有玩家的合法我方自由飞行弹幕；不吸收队友的持握弹幕、召唤物和任何不在白名单的专有弹幕。 |
| 目标死亡 | 5 秒内目标死亡时，吸积核立即转移到被动规则选出的下一名有效目标；没有目标则提前结束。已吸积弹幕改为向新目标飞行。 |
| 结束 | 持续时间结束时，吸积核造成一次 `220%` 的收束爆炸，半径 `260 px`；然后清除吸积状态。 |

大招不应给目标施加右键“虚空烙印”，也不清除已有虚空烙印；它们是独立系统。

## 7. 配饰体系总则

本武器有 **4 件主线核心** 和 **6 件支线配饰**，总计 10 件。

* 主线是严格的 `Alpha → Gamma → Sigma → Omega` 合成链；后级配方消耗前级，装备时只允许其中一件生效。`CanAccessoryBeEquippedWith` 必须阻止通过作弊或复制同时装备两个主线核心。
* 支线可与任意一件主线、也可互相同时装备；它们占用正常饰品栏，强度以饰品栏位为代价，而不是人为限制为“最多两件”。
* 所有配饰效果只在玩家手持黑洞导弹时生效；除非效果文字明确说明，绝不提升其他远程武器或全局伤害。
* 每件配饰使用单独的 `ModPlayer` 布尔值/数值，并在 `ResetEffects` 中重置；不要用静态字段保存装备状态。
* 以下配方均使用无尽虚空阶段可得材料，不使用神明吞噬者之后的未来材料。`Dark Plasma` 为灾厄暗等离子，`Luminite Bar` 为夜明锭。

## 10. 废案：方案二「环轨反演」

### 原始方案

玩家按传奇技能键蓄力时不举起火箭筒，而是旋转火箭筒并吸收黑色粒子。蓄力完成后按左键收起火箭筒，在玩家周围生成几乎铺满屏幕、只能顺时针旋转的黑洞。

黑洞持续 5 秒：

1. 与黑洞接触的敌方弹幕被转化为我方；
2. 转化后的弹幕进入以玩家为中心的顺时针公转轨道；
3. 持续结束后，全部转化弹幕同时冲向鼠标位置或附近敌人。

### 不采用的原因

该方案的视觉和幻想非常强，但不进入第一版实现，理由如下：

* 敌方弹幕类型极多。直接改写 `hostile/friendly/owner/DamageType/ai` 会破坏大量 Boss 或其他模组的专有 AI；
* 许多敌方弹幕是持握物、激光、碰撞箱代理、Boss 行为状态机的一部分，删除或转化它们可能令 Boss 卡状态，甚至崩溃；
* 将数十到数百个不同弹幕纳入同一玩家公转轨道，需要逐个保存和还原原始速度、AI、伤害、拥有者、tileCollide 与网络状态，联机成本极高；
* 即使只对白名单弹幕生效，也会使玩家无法凭视觉理解“哪些弹幕会被转化、哪些不会”，违背传奇武器应有的可靠反馈。

### 若未来要复活此方案

只能采用“复制而不转化”的安全版本：黑洞接触敌方弹幕时保留原敌方弹幕，额外生成无伤害或固定伤害的视觉复制体进入轨道；原敌弹仍按原轨迹存在。这样虽然保住演出，但不再是“化敌为友”，因此不作为黑洞导弹当前的大招。

---

## 11. 最终验收标准

完成后的黑洞导弹必须让玩家在不看文档的情况下感受到以下四件事：

1. **我装什么，就不是同一把左键。** 手榴弹下坠分裂、普通火箭单体制导、集束递归乱舞、核弹天降控场的节奏必须一眼可辨。
2. **右键不是免费跟踪炮。** 它越大越强，也越不听话；满级提示到来时，发射导弹的决定应当紧张而明确。
3. **黑线在帮我挑最值得打的目标。** Boss 永远优先、无敌部位永远不被标、蠕虫身体永远不被错误增伤。
4. **大招让全队火力汇于一点。** 终末吸积的画面是“屏幕内的子弹被一颗目标上的黑洞拉进去”，而不是又一个普通范围核爆。
