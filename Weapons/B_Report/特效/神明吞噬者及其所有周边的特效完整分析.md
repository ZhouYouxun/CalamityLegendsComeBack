# 第一章：DoG色彩体系

## 1.1 核心动态颜色公式（DevourerofGodsHead.cs）

```csharp
public static Color SpecialMoveColor =>
    Color.Lerp(Color.Fuchsia, Color.Cyan,
        MathHelper.SmoothStep(0, 1,
            (MathF.Sin(Main.GlobalTimeWrappedHourly * 2) + 1) * 0.5f));
```

- **Color.Fuchsia** = RGB(255, 0, 255) 品红/洋红
- **Color.Cyan**    = RGB(0, 255, 255) 青色
- SmoothStep使过渡更平滑（S曲线），周期约π秒（约3.14秒一个来回）

## 1.2 完整DoG色板

| 名称 | RGB / 来源 | 典型用途 |
|------|-----------|---------|
| DoGColor（动态） | Fuchsia ↔ Cyan（上述公式） | 所有主体特效 |
| DoGDistortionPurple | RGB(136, 26, 186) | DoGDistortionMetaball边缘色 |
| DoGLightBlue | DoGSky.DoGLightBlue | 现实裂缝高亮色 |

```csharp

        position: Projectile.Center + rand.NextVector2Circular(60f, 60f),
        velocity:  rand.NextVector2Circular(20f, 20f),

        lifetime:  rand.Next(12, 25),

    GeneralParticleHandler.SpawnParticle(new SquishyLightParticle(
        velocity:     Projectile.DirectionFrom(spawnPos) * rand.NextFloat(5f),
        color:        rand.NextBool() ? Color.Cyan : Color.Fuchsia,
        squishRatio:  0.5f,
        lifetime:     8,
        scale:        0.15f));

// 每5帧：ShineExplosion2脉冲
if (Time % 5 == 0)
    GeneralParticleHandler.SpawnParticle(new CustomPulse(
        Color.White * 0.6f, 0.2f, 1.2f, "CalamityMod/Particles/ShineExplosion2"));

// 递增震屏
CalamityUtils.AddScreenshakeAt(Projectile.Center, 2f + chargeInterpolant * 4f);

// 现实裂缝着色器参数
```
