# 物资官

使用用户提供的 `E:/特殊NPC.png`：40×1400，25 帧，每帧 40×56；游戏主体图片逐字节保留，头像从第一帧提取。
原图朝右，与原版城镇 NPC 的贴图朝向相反。沿用向导的城镇 NPC 行走动画，并在 `PreDraw` 中直接交换左右绘制方向；不修改行走帧，也不根据移动速度猜测朝向。贴图像素保持原样。
正常城镇 NPC，有空房即可等待入住，无额外 Boss 入住门槛。职业称号是物资官；个人名从六个中英文名字中随机选取。旧版本中个人名仍为“物资官”的 NPC 会自动改名。
快乐度：喜欢森林、机械师和商人；不喜欢沙漠、爆破专家和渔夫。渔夫的理由是说话没大没小、不讲礼貌。

对话中的“下一页”只切换当前页和第一个按钮的名称，需要再次点击第一个按钮打开商店。商店右侧是单个“>>>”按钮，点击后直接切换到下一页商品并保持商店打开。
页面在当前玩家的 ModPlayer 中记录，不存到世界或 NPC，不需要同步给其他玩家。再次对话保留当前页，进入世界时重置。

物资官替代了旧的传奇商人；本模组不再给动物学家追加 Boss 召唤物及两把鱼武器，不再给商人追加补给包，也不再给巫师追加传送杖、给机械师追加德莱多恩电池。其他 NPC 的非重复快捷商品仍保留。

## 进度规则

- Boss 页复用原召唤物列表与价格，保留首杀前购买例外；动物学家不再出售本模组添加的召唤物。
- 密码破译机有底座、5 个升级组件（含金源量子冷却电池）、普通电池、燃料电池工厂、充能台、5 张图纸。五张图纸开局即可购买；前四个升级组件只检查世界进度，不需要解密图纸；金源量子冷却电池仍检查第五阶段解密知识。高级显示屏还检查冰灵、世纪之花、石巨人进度。
- 矿石分为原版与灾厄各一页：原版页含全部原版矿石、黑曜石、7 种宝石；灾厄页含 11 种矿石（含海棱晶、狱烬石、夜明珠），不出售未注魔的天蓝矿。秘银/山铜和精金/钛金尊重灾厄“肉后进度重做”开关及机械 Boss 击杀数量；星辉矿须星神后，亵渎晶矿须亵渎天神后，金源矿须犽戎后。
- 材料取自 `SHPCEffectRegister` 的 41 个有效 AmmoType，但不出售纯合成的 CoreofCalamity、AscendantSpiritEssence、LoreCynosure，因此 38 件商品在一页内。血石效果实际装填 Bloodstone；深渊细胞按当前灾厄的利维坦条件；四柱碎片分别在击败对应柱后售卖。
- 高价值物品按解锁时期排列：卢克索的礼物、冰立方、钨钢屏障生成仪及新增六件饰品／雕像开局可买；闪光皇后鱼为沙漠灾虫后；硫火喷吐鱼、旧神阔剑、剑锋之誓约由本角色首次进入地狱后解锁；石约与胜利之剑、鬼妖村正、传送杖、深渊咒符、吸音隔板为肉后；钱币枪为肉后海盗入侵后；博比特虫钩为幽花后；终焉百合为犽戎后。地狱到访记录保存在角色数据中。
- 补给包第二位为复古游戏机补给包，第三位为 QuickStartBox；第一位的 `LongLostWeaponBlueprints` 显示为“失传已久的武器图纸”。其余为六种阶段补给包。开荒包须邪恶 Boss 和哥布林军队后；肉后包须至少一机械且精金/钛金已解锁；花后包还须灾厄之影；月后包还须世纪之花。商人不再出售这些补给包。

现有召唤物、补给包价格沿用；新增单品使用“默认买价和分类最低价取较大值”，防止免费商品。传送杖 1 铂、钱币枪 1 铂、博比特虫钩最低 2 铂、终焉百合最低 5 铂，开局饰品与雕像最低 15 金，两把鱼武器 50 金。

## 验证

`.codex-tools/verify_quartermaster.py` 使用真实商品构建代码与简化游戏 API 运行 290 项检查，验证分页、原版与灾厄矿石分组、五张图纸开局可买、升级组件知识门槛、机械 Boss 全部组合/配置及关键后期门槛。另比对 41 个有效 SHPC 材料中实际售卖的 38 件、源贴图 SHA-256。此检查不是实际游戏运行测试。

源代码编译通过，保留已有的 3 个 CS0169 警告；中英 HJSON 经实际 Hjson 库解析通过。打包后检查新增主体/头像 rawimg 和中英文本存在。打包器的 unknown image type 警告并未阻止新增两张图片转换。

尚需游戏内确认：入住、走路/坐下/攻击动画、不同 UI 缩放下的连续翻页、多玩家同时交谈、各进度存档实际购买。
