# 沙漠之鹰传奇弹仓形态移除前设计报告

> 记录时间：2026-07-05
> 参考版本：`a3bccfbc1af67e9a5bc4dff65cb37262614b304d` (`Sync July 5 fixes to DEV`)
> 目的：保存被移除前的“传奇弹仓形态”设计、注册表、属性含义、UI 写法与还原路径。

## 一句话概括

传奇形态的沙漠之鹰不再使用旧版“三次散射 + 一发吸血弹”的固定节奏，而是变成一把“可装填其他枪械灵魂”的开发者武器：

- 左键固定为 300 RPM 单发精准射击。
- 左键发射统一弹幕 `DELeftBullet`。
- `DELeftBullet` 根据弹仓中装填的枪械 ItemType 选择 `DEBulletRule`。
- 弹仓为空或枪械未注册时，走默认 `DEDefaultBulletRule`，效果接近旧 `DesertEagleLifeRound`。
- 背包中对沙漠之鹰按中键打开单格弹仓 UI。
- 鼠标拿着已注册枪械时，可以放入、取出或交换弹仓里的枪。
- 右键仍是旋转本体、蓄力、命中敌人，并可在满蓄后发射重弹。
- 特殊联动：弹仓装填 `Hellborn` 时，右键旋转本体撞击敌人会爆炸，并给左键短暂过载提速。

## 本体 `DesertEagle.cs`

传奇形态本体承担三个职责：左键入口、右键入口、弹仓规则调度。

关键命名空间：

- `CalamityLegendsComeBack.Weapons.A_Dev.DesertEagle.LeftClick`
- `CalamityLegendsComeBack.Weapons.A_Dev.DesertEagle.LeftClick.Rules`
- `CalamityLegendsComeBack.Weapons.A_Dev.DesertEagle.Slot`

关键属性：

| 属性 | 值/默认 | 目的 |
| --- | --- | --- |
| `SilverVolleyDamage` | `200` | 历史遗留和旧派生武器接口；传奇弹仓左键主要改用 `LifeRoundDamage`。 |
| `LifeRoundDamage` | `1981` | 左键统一子弹基础伤害；右键 holdout 生成伤害也以它为基准。 |
| `HoldoutSpinContactDamageMultiplier` | `0.31f` | 右键旋转本体接触敌人的伤害倍率。 |
| `HoldoutFullChargeRoundDamageMultiplier` | `22.0f` | 右键满蓄后重弹的伤害倍率。 |
| `PrimaryVolleyProjectileType` | `-1` | 旧 A_Olds 派生枪兼容钩子；基础沙漠之鹰不用。 |
| `LifeRoundProjectileType` | `DesertEagleLifeRound` | 旧派生武器兼容钩子。 |
| `ChargedRoundProjectileType` | `DesertEagleHeavyRound` | 右键满蓄重弹类型。 |
| `UsesSilverVolleyVisuals` | `true` | 旧散射视觉兼容开关。 |
| `HasDesertEaglePrimaryFire` | `true` | 允许某些派生枪只保留右键框架。 |
| `HasDesertEagleSpin` | `true` | 控制是否允许右键旋转。 |

左键逻辑：

1. `CanUseItem` 禁止右键普通使用。
2. 左键固定 `Item.damage = LifeRoundDamage`。
3. 普通状态 `useTime/useAnimation = 12`，约 300 RPM。
4. 如果 `DesertEaglePlayer.HellbornOverdriveActive` 为真，改成 `useTime/useAnimation = 5`，`shootSpeed = 22f`。
5. `Shoot` 中读取：
   - `DesertEagleSlotPlayer slotPlayer`
   - `DEBulletRegistry.GetRule(slotPlayer.SlottedGunType)`
6. 根据规则伤害倍率计算：
   - `bulletDamage = GetConfiguredWeaponDamage(player, LifeRoundDamage) * rule.DamageMultiplier`
7. 生成统一弹幕：
   - 类型：`ModContent.ProjectileType<DELeftBullet>()`
   - `ai[0] = slotPlayer.SlottedGunType`
   - `ai[1] = rule.GetShotExtra(slotPlayer)`

右键逻辑：

- 仍通过 `DesertEagleHoldout` 实现。
- 按住右键隐藏手持物品并生成 holdout。
- holdout 负责旋转、蓄力条、接触伤害、满蓄重弹。
- `DesertEagleHellbornGlobalProjectile` 会额外监听 holdout 命中，以实现 Hellborn 爆炸/过载。

配方：

```csharp
CreateRecipe().
    AddIngredient<PearlGod>(1).
    AddIngredient<Hellborn>(1).
    AddIngredient<CosmiliteBar>(8).
    AddIngredient<DarksunFragment>(5).
    AddTile<CosmicAnvil>().
    Register();
```

## 弹仓状态 `Slot/DesertEagleSlotPlayer.cs`

这是传奇形态最核心的存档状态。

| 字段/属性 | 作用 |
| --- | --- |
| `Item SlottedGun` | 当前弹仓中装填的枪。`IsAir` 表示为空。 |
| `int SlottedGunType` | 当前装填枪的 `Item.type`；空则返回 0。 |
| `int CardIndex` | `AcesHigh` 牌型计数器，0 红心、1 梅花、2 方块、3 黑桃。 |
| `bool ToggleState` | 交替型规则状态，原本预留给 `Arietes41` / `ThermoclineBlaster`。 |
| `int BurstCounter` | `PridefulHuntersPlanarRipper` 的每 4 发强化计数。 |

存档：

- `SaveData` 只保存 `DEGunItemID = SlottedGun.type`。
- `LoadData` 只根据 type 新建 `new Item(type)`。
- 不保存 stack、prefix、modded item 额外数据；设计上弹仓只关心“哪把枪”，不关心那把枪本身的个体属性。

## UI `Slot/DesertEagleSlotUI.cs`

UI 是一个纯静态覆盖层，不走复杂 UIState。

核心结构：

| 成员 | 作用 |
| --- | --- |
| `PanelW = 200` / `PanelH = 100` | 面板大小。 |
| `SlotSize = 52` | 单格弹仓大小。 |
| `IsOpen` | UI 是否打开。 |
| `opacity` | 淡入淡出透明度。 |
| `closing` | 正在关闭。 |
| `PanelRect` | 居中偏上的面板矩形。 |
| `SlotRect` | 面板中央偏下的 52x52 弹仓格。 |

绘制层：

- 由 `DesertEagleSlotInputSystem.ModifyInterfaceLayers` 插入到 `"Vanilla: Mouse Text"` 前。
- 使用 `LegacyGameInterfaceLayer`。
- 使用 `InterfaceScaleType.None`。
- 因为使用 `InterfaceScaleType.None`，鼠标坐标直接用 `Main.mouseX/Main.mouseY`，不能再除 UI scale。

打开方式：

- 背包打开时，鼠标悬停沙漠之鹰本体。
- 按中键。
- `DesertEagleSlotInputSystem.DetectInput` 检测：
  - `Main.playerInventory`
  - `Main.mouseMiddle && !prevMouseMiddle`
  - `Main.HoverItem?.type == ModContent.ItemType<DesertEagle>()`
- 满足后调用 `DesertEagleSlotUI.Toggle(Main.LocalPlayer)`。

关闭方式：

- 再按一次中键可触发 `BeginClose`。
- 背包关闭时自动淡出。
- 淡出到 `opacity <= 0` 时 `IsOpen = false`。

交互规则：

| 鼠标物品 | 槽内状态 | 行为 |
| --- | --- | --- |
| 已注册枪 | 空槽 | 克隆鼠标物品，`stack = 1`，放入槽，鼠标物品清空。 |
| 空鼠标 | 有枪 | 把槽内枪克隆到鼠标，槽清空。 |
| 已注册枪 | 有枪 | 交换鼠标枪和槽内枪。 |
| 未注册物品 | 任意 | 不允许放入，悬停边框变红。 |

UI 反馈：

- 已注册枪悬停：边框偏绿。
- 错误物品悬停：边框偏红。
- 空手或普通悬停：边框偏白。
- 槽内有物品时绘制对应物品贴图，并设置 `Main.hoverItemName`。
- 槽为空时显示 `Empty`。
- 底部提示：
  - 空槽：`Left-click to slot a pistol`
  - 有枪：`Left-click to retrieve`

鼠标拦截：

- 鼠标在面板范围内时：
  - `player.mouseInterface = true`
  - `Main.blockMouse = true`
- `PreUpdatePlayers` 也在 UI 打开且鼠标位于面板时设置 `mouseInterface`，避免误操作。

## 注册系统

### `DEBulletRegistry`

这是运行时注册表：

| 成员 | 作用 |
| --- | --- |
| `Dictionary<int, DEBulletRule> Rules` | `GunItemType -> Rule`。 |
| `DEDefaultBulletRule DefaultRule` | 弹仓空/未注册时的默认规则。 |
| `Register(DEBulletRule rule)` | 按 `rule.GunItemType` 注册规则。 |
| `GetRule(int gunItemType)` | 找到对应规则，否则返回默认规则。 |
| `IsRegisteredGun(int itemType)` | UI/tooltip 判断是否可装填。 |
| `AllRules` | 遍历所有规则。 |
| `Clear()` | 清空注册表。 |

### `DEBulletRegistrationSystem`

注册发生在 `PostSetupContent()`，卸载时 `Clear()`。

注册分组：

| 分组 | 规则 |
| --- | --- |
| A 经典手枪 | `CrackshotColt`、`Fungicide`、`SlagMagnum`、`PhoenixBlaster` |
| B 硬模 | `MidasPrime`、`Needler`、`ThermoclineBlaster`、`Arietes41`、`Helstorm` |
| C 植物后 | `Hydra`、`PestilentDefiler`、`AstralBlaster`、`Hellborn` |
| D 终局 | `GoldenEagle`、`PearlGod`、`StellarCannon`、`PridefulHuntersPlanarRipper`、`AcesHigh` |

## 统一弹幕 `LeftClick/DELeftBullet.cs`

`DELeftBullet` 是所有左键弹幕的统一载体。

AI 字段：

| ai | 含义 |
| --- | --- |
| `ai[0]` | 装填枪的 `ItemType`；0 表示无枪，走默认规则。 |
| `ai[1]` | 规则自定义额外数据，如弹射次数、牌型、是否强化、冰火分支。 |

生命周期：

1. `SetDefaults` 给出通用默认弹幕：
   - 6x6
   - ranged
   - `penetrate = 1`
   - `timeLeft = 600`
   - `extraUpdates = 4`
   - `tileCollide = true`
   - 本地 NPC 免疫
2. `OnSpawn` 读取 ActiveRule，并应用：
   - `Penetrate`
   - `ExtraUpdates`
   - `ArmorPenetration`
   - `SpeedMultiplier`
   - `SetDefaults`
   - `OnSpawn`
3. `AI/ModifyHitNPC/OnHitNPC/CanHitNPC/OnTileCollide/OnKill/PreDraw/PostDraw` 全部转发给规则。

这套设计的好处是：沙漠之鹰本体只生成一种弹幕，真正的“哪把枪带来什么效果”全部被封在规则里。

## 规则基类 `DEBulletRule`

可覆写属性：

| 属性/方法 | 默认 | 目的 |
| --- | --- | --- |
| `GunItemType` | 抽象 | 激活本规则的枪械 ItemType。 |
| `Penetrate` | `1` | 弹幕穿透数。 |
| `ExtraUpdates` | `4` | 弹幕速度/更新频率。 |
| `ArmorPenetration` | `0` | 护甲穿透。 |
| `SpeedMultiplier` | `1f` | 生成后速度倍率。 |
| `DamageMultiplier` | `1f` | 基于沙漠之鹰 `LifeRoundDamage` 的伤害倍率。 |
| `GetShotExtra(slotPlayer)` | `0f` | 写入 `ai[1]` 的每发额外数据。 |
| `SetDefaults(projectile)` | 空 | 进一步覆盖弹幕属性。 |
| `OnSpawn(projectile, owner)` | 空 | 生成瞬间逻辑，如追加副弹。 |
| `AI(projectile, owner)` | 空 | 每帧行为。 |
| `ModifyHitNPC` | 空 | 命中前修改伤害。 |
| `OnHitNPC` | 空 | 命中后效果。 |
| `CanHitNPC` | `null` | 自定义能否命中。 |
| `OnTileCollide` | `true` | 撞墙逻辑。 |
| `OnKill` | 空 | 消失逻辑。 |
| `PreDraw` | `true` | 自定义绘制；true 走 `DELeftBullet` 默认后像。 |
| `PostDraw` | 空 | 后绘制。 |
| `TooltipEffectEN/ZH` | 空 | 给已注册枪械 tooltip 显示的效果说明。 |

## 默认规则

`DEDefaultBulletRule` 负责弹仓为空时的行为。

效果：

- 基本照搬 `DesertEagleLifeRound`。
- 银色螺旋尾迹。
- 命中回复造成伤害的 8%。
- 命中/撞墙产生银色冲击特效。
- 中文 tooltip：`银色弹幕，命中回血8%`。

## Hellborn 右键联动

文件：`DesertEagleHellbornGlobalProjectile.cs`

作用对象：

- 只应用于 `DesertEagleHoldout`。

触发条件：

1. holdout 正在旋转，即 `projectile.ai[2] == 0f`。
2. 爆炸冷却为 0。
3. 玩家存活。
4. `DesertEagleSlotPlayer.SlottedGunType == ModContent.ItemType<Hellborn>()`。

触发效果：

- `explosionCooldown = 26`。
- `ActivateHellbornOverdrive(180)`，让左键 180 帧内进入过载。
- 玩家反冲 `owner.velocity -= direction * 2.5f`。
- 屏幕震动 7。
- 播放爆炸音效。
- 生成 `DEBulletUtils.SpawnAreaBurst`，伤害约为本次命中伤害的 `1.25f`，范围 `132f`。

本联动容易漏还原；只恢复 `LeftClick/` 和 `Slot/` 不会自动恢复右键 Hellborn 爆炸。

## 还原时最容易漏的点

1. `DesertEagle.cs` 的 using 必须恢复 `LeftClick`、`LeftClick.Rules`、`Slot`。
2. `Shoot` 必须重新生成 `DELeftBullet`，并传入 `ai[0] = SlottedGunType`、`ai[1] = rule.GetShotExtra(slotPlayer)`。
3. `DesertEaglePlayer` 必须恢复 `hellbornOverdriveTime`、`HellbornOverdriveActive`、`ActivateHellbornOverdrive`。
4. `DesertEagleHellbornGlobalProjectile.cs` 必须恢复，否则 Hellborn 只剩左键规则，没有右键爆炸/过载。
5. `Slot/DesertEagleSlotInputSystem.cs` 必须恢复，否则 UI 文件存在但不会被绘制，也不会检测中键。
6. `Slot/DesertEagleGunTooltipGlobal.cs` 必须恢复，否则枪械不会提示“可装填至沙漠之鹰”。
7. `DEBulletRegistrationSystem.cs` 必须恢复，否则所有枪都无法被 UI 识别为可装填。
8. 本地化要恢复 DEBullet 系列显示名，否则弹幕名会缺失。
9. 如果以后要把它做成真正可绑定按键，不要只改 tooltip；当前代码实际只检测了中键。
10. 如果改成多人完全同步弹仓内容，需要扩展 `DesertEagleSlotPlayer` 的网络同步；旧形态只做了存档读写，没有额外 net sync。

## 设计评价

这个形态的优点是扩展性强：新增一把可装填枪只需要新增一个 `DERule_*` 并在 `DEBulletRegistrationSystem` 注册，UI、tooltip、左键发射入口都能自动接上。

它的问题也很明确：沙漠之鹰本体的身份会被弹仓规则盖过去，左键从“沙漠之鹰自己的节奏武器”变成“其他枪械效果播放器”。如果以后想重做但不想再次吞掉本体风格，建议保留弹仓 UI，但让装填枪只改变副效果，不改变左键主节奏。
