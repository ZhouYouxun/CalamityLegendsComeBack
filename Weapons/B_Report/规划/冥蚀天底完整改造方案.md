# 冥蚀天底：开局成长型传奇武器完整改造方案

> 状态：设计与实现交接稿。本文只定义目标、行为、数值边界和文件职责，不直接修改武器代码。
>
> 核心定位：**开局可取得、随 Boss 进度成长的传奇近战长矛**。它不是月后奖励武器，也不是终局全自动清场器；它应在每个阶段都给玩家一套明确、好学且会随数值成长而变强的战斗语言。

## 1. 最终战斗语言

| 输入 | 战斗职责 | 玩家感受 | 不应承担的职责 |
| --- | --- | --- | --- |
| 左键 | 近距离扫群、压制正面敌人 | 三段矛法，第三段冲刺收招 | 自动追踪、长时间驻场、持续召唤物 |
| 右键 | 中远距离点杀与补刀 | 两发“沿路唤魂”铺垫，第三发立即终爆 | 站桩自动清屏、贴脸主输出 |
| 按住左键再按右键 | 近身回旋斩迹模式 | 进入稳定的旋转防线，处理贴身包围 | 代替左键三段或右键投矛的全部功能 |

一句话：**左键把敌群斩开，右键把远方钉穿，双键把贴身敌人卷走。**

## 2. 先处理的结构性问题

### 2.1 保留成长表，修正获取与文本

`UmbralNadirBalance.StageTable` 的阶段成长正符合“开局传奇”的定位，应保留，不应因材料目前偏月后就删除。

但当前配方使用原版天底、日耀锭、暗日碎片和扭曲虚空，和“开局可取得”冲突。实现者必须与数值/掉落负责人确认二选一：

1. 将武器本体的取得方式改为开局传奇来源（首领首杀、极低概率宝箱、任务/世界事件等），保留成长表；或
2. 若当前配方暂时不改，至少不要在玩家可见文本中把它包装为“开局取得”。

推荐方案是第一种。成长伤害应只由 `UmbralNadirBalance` 统一管理；不要在新投射物里按世界进度重复判断。

### 2.2 删除“驻场深渊生态”

以下现有链路与本次定位冲突，必须从左右键的常规命中中移除：

- 左键命中生成 `UmbralNadirAbyssRift`；
- 裂隙在 96 帧内重复吐出 `VoidTentacle`；
- 右键投矛爆炸后生成会追踪、分裂、再放触手的 `UmbralNadirVoidEssence`；
- 所有由上述链路带来的二次、三次自动伤害。

原因不是它们“不够酷”，而是它们让武器从玩家操作的长矛，变成命中一次后自己接管战场的弹幕发生器。左键的群攻应来自**命中瞬间的爆炸范围**；右键前两发的延迟价值应来自**少量、可读的沿途暗影灵魂**。

`UmbralNadirAbyssRift.cs` 与 `UmbralNadirVoidEssence.cs` 可以先保留在工程中，避免误伤其他引用；本武器改完后若无任何引用，再由负责人决定是否删除。

## 3. 左键：三段近战与命中爆炸

### 3.1 连段动作：保留，不重做

保留 `UmbralNadirHoldout` 的三段动作、固定 26 帧节奏、40 帧断连重置，以及第三段的向瞄准方向冲刺。三段伤害倍率暂定继续使用：

| 段数 | 动作 | 本体倍率 | 命中爆炸倍率 | 爆炸半径 |
| --- | --- | ---: | ---: | ---: |
| 1 | 上挑斩 | 1.00 | 0.28 | 72 px |
| 2 | 劈落斩 | 1.20 | 0.36 | 88 px |
| 3 | 冲刺贯穿（必暴） | 1.70 | 0.55 | 112 px |

爆炸伤害以**当前 holdout 的实际伤害**为基准，即已经含左键成长伤害和本段倍率的弹幕伤害；爆炸必须使用局部 NPC 无敌帧，建议 `usesLocalNPCImmunity = true`、`localNPCHitCooldown = 10`。这样它能扫群，但不会在大体型 Boss 身上叠成多段霰弹。

第三段保留必暴，但不要再额外附加裂隙、触手环与第二道随机裂隙。第三段强，是因为它可靠地更大、更响、更有位移，而不是因为它比前两段多出四种自动弹幕。

### 3.2 左键挥舞特效：矛尖黑色着色器 + 黑色颗粒

用户明确要求：挥舞期间**不要黑色 GlowSpark / GlowSpark2**。下列调用必须从 `SpawnSwingParticles` 移除：

- `CustomSpark(... "CalamityMod/Particles/GlowSpark2", Color.Black, ...)`；
- 任何黑色 `AltSparkParticle` / 黑色闪电火花式效果；
- 沿矛身密集铺设的黑绿双火花。

改为两层，且只服务于矛尖，不要覆盖整根枪身：

1. **矛尖黑色着色器拖痕（主视觉）**
   - 在 `PreDraw` 中由最近 6–8 帧的“矛尖世界坐标”构造短 Primitive trail；不要直接用 `Projectile.oldPos`，应以旧中心位置加上旧旋转导出的矛尖偏移。
   - 使用现有的 `GameShaders.Misc["CalamityMod:TrailStreak"]`，纹理可继续用 `SylvestaffStreak`；颜色函数固定为 `Color.Black → Color.DarkGray`，末端允许极少量 `new Color(35, 90, 45)`，不使用亮绿发光尾。
   - 宽度建议由矛尖端的 26 px 收至 3 px；只在 `inSwing` 时绘制。第三段可将最大宽度提高至 38 px，并增加 0.08 的低频扭曲感，但不能变成整屏剑气。
   - 这是“吞光的黑色矛尖残像”，不是普通黑烟，也不是 Spark。

2. **黑色颗粒（辅视觉）**
   - 每个真实游戏帧最多 1–2 粒，从矛尖后方 10–32 px 随机逸出；`Projectile.FinalExtraUpdate()` 是唯一允许产生的时机。
   - 颗粒应是小、短命、无发光的黑色粒屑：优先使用黑色/近黑色的普通 Dust 或小尺寸 `GenericBloom(Color.Black)`；寿命 8–14 帧，缩放约 0.18–0.38。
   - `VoidDustInverted` 只能低频（每 3 个真实帧最多 1 粒）作为深渊识别点，不要把它当作主粒子，否则荧绿边缘会重新抢走矛尖着色器的主视觉。
   - 禁止 `HeavySmokeParticle` 的大团黑烟，禁止每帧三段式连发粒子。画面要像黑色砂粒从矛尖被甩出，不像着火或冒烟。

### 3.3 左键命中：一次猛烈、短促、可读的爆炸

新增 `LeftClick/UmbralNadirImpactExplosion.cs`，专门处理左键命中范围伤害和视觉；不要借用 `AbyssRift`。

行为规格：

- `timeLeft = 12–16`，`tileCollide = false`，只在前 2–3 帧可造成伤害；
- 仅在 `OnHitNPC`、且 `Projectile.owner == Main.myPlayer` 时生成；
- 视觉顺序为：黑色短促坍缩核（AlphaBlend）→ 一圈克制的荧绿边缘（AfterEverything）→ 10–16 粒黑色粒屑向外甩出；
- 第一、二段不震屏；第三段只允许约 `2.5–3.5` 的短震屏；
- 不生成裂隙、不生成触手、不生成追踪灵魂、不持续停留。

这会让“群攻”来自清晰的命中点范围，而非玩家看不懂的后续自动链。

## 4. 右键：高速三连投矛

### 4.1 投矛速度与散布

当前 `ThrowJavelin` 速度是 `3.6–4.6`，且投矛有 `extraUpdates = 3`，实际飞行虽然不算静止，但手感仍偏飘。按用户要求，最大速度提升到当前最大值的 120%。

建议实现为：

```csharp
float speed = Main.rand.NextFloat(4.8f, 5.52f); // 最大值 4.6 × 1.20
float spread = MathHelper.ToRadians(Main.rand.NextFloat(-4f, 4f));
```

同时将横向出生偏移从 `±30 px` 收至 `±14 px`，前向出生距离维持 `24–44 px`。这样仍有三发不完全重叠的活力，但不再像散射飞镖。

三发节奏仍是 0 / 5 / 10 帧，轮间停顿 35 帧。不要以提高射速替代提高飞速。

### 4.2 前两发：沿路唤出的暗影灵魂

这里借鉴旧作 `NadirJavPROJ.cs` 的**空间叙事**：投矛飞过时，阴影在它周边被刺破，暗影灵魂从路过区域钻出并主动追敌。

但不复制旧实现：旧实现在飞行 15 帧后每 10 帧生成一次、上限 25 个，出生点可在投矛下方约 800–960 px，且伤害为投矛的 75%。这个规模不适合本武器，也不适合开局成长型设计。

新增 `RightClick/UmbralNadirShadowSoul.cs`。前两发（`ShotIndex` 为 0 或 1）使用以下规则：

| 项目 | 规格 |
| --- | --- |
| 发射时机 | 投矛存活满 8 帧后，每 9 帧检查一次 |
| 单矛上限 | 最多 3 个暗影灵魂；单次只生成 1 个 |
| 出生位置 | 投矛后方 140–280 px，加垂直方向 `±80 px` 随机偏移；必须是“沿飞行路线附近”，不是地图任意位置 |
| 目标 | 出生后寻找 600 px 内、可追击的最近敌人；无目标时最多直飞/漂移 18 帧后淡出 |
| 追踪 | 先用 8 帧转向进入轨道，再以 9–11 px/帧追踪；不可穿墙追踪 |
| 伤害 | 每个灵魂为投矛伤害的 0.20–0.24 倍，仅命中一次 |
| 命中 | 施加短暂 `Voidfrost`，小型黑核闪烁 + 4–6 粒黑色粒屑 + 1 个小绿边缘脉冲；不分裂、不放触手 |

用户描述中的“额外的四针/暗影灵魂”在这里按“针状、小型暗影灵魂”实现理解；视觉做成细长的黑色魂针，不做圆形追踪核心。若原意是“每一矛固定四枚”，只需要把单矛上限从 3 改为 4，其他边界不变。

灵魂必须由拥有者客户端生成，并通过投射物正常同步；不允许在每个客户端各自随机生成。随机数、计时和总数必须存储在 projectile 的 AI/localAI 或 ExtraAI 中，不能只靠未同步的普通字段决定战斗结果。

### 4.3 第三发：立即终爆，不带滞后灵魂

第三发（`ShotIndex == 2`）是终结矛：它飞得和前两发一样快，但**完全不生成 `UmbralNadirShadowSoul`**。

命中 NPC 时：

1. 先正常造成投矛本体伤害；
2. 立刻在目标中心生成一次 `UmbralNadirFinalExplosion`；
3. 终爆在前 2 帧造成一次范围伤害，半径建议 132 px、伤害为第三发投矛伤害的 0.65 倍；
4. 视觉是“黑核收缩一拍后炸开”：黑色 AlphaBlend 核心、一个荧绿外环、16–24 粒黑色颗粒、极轻的 3.5–4.0 震屏；
5. 不生成灵魂、不生成触手、不生成裂隙、不进入持续伤害状态。

撞墙和超时只能出现一个约 45% 尺寸的**无伤害熄灭特效**，绝不能同样触发终爆；否则玩家会把第三发当作远程地雷，违背“命中敌人直接爆炸”的设计。

### 4.4 现有 `OnKill` 的改造原则

当前 `UmbralNadirJavelin.OnKill` 无条件调用 `Explode()`，因此命中、撞墙、超时都是一套爆炸与召唤链。必须拆分为：

- `OnHitNPC`：记录 `HitEnemy = true`，第三发生成终爆；前两发只给命中 Debuff；
- `OnTileCollide` / `OnKill`：仅播放小型熄灭 VFX；
- 灵魂生成完全放在前两发的飞行 AI 中；
- 删除 `SpawnVoidEssence`、`SpawnTentacle` 及其所有调用。

## 5. 双键：回旋斩迹模式

### 5.1 输入规则，必须无歧义

触发方式为：**玩家已经按住左键、左键 holdout 正在存在时，再按下右键。**

| 玩家状态 | 结果 |
| --- | --- |
| 仅左键 | 正常三段近战 |
| 仅右键 | 正常高速三连投矛 |
| 左键 holdout 存在 + 右键刚按下 | 立刻杀死左键 holdout，生成回旋斩迹 holdout |
| 回旋斩迹中仍按住左键和右键 | 持续维持 |
| 松开任一按键 | 立即结束，不自动补投矛或补连段 |

这条规则取代当前“右键无条件优先、打断左键后一定投矛”的逻辑。右键单独按是投矛；右键作为左键按住期间的第二输入才是回旋。

### 5.2 不照搬 DragonRage：只借输入模型

参考 `DragonRageJavPROJ.cs` 的正确部分是“一个独立常驻弹幕根据按键维持、控制玩家手臂和旋转”；不应复制其 420×420 碰撞箱、火焰召唤、吸引模式、持续震屏或复杂状态机。

新增 `Combo/UmbralNadirSpinHoldout.cs`，推荐参数：

| 参数 | 建议 |
| --- | --- |
| 存续 | 仅双键同时按住时刷新 `timeLeft = 2` |
| 旋转 | 约 0.36–0.44 rad/帧，方向由首次触发时的瞄准方向/玩家朝向确定 |
| 半径 | 矛尖离玩家 92–118 px，随旋转略微呼吸，不要覆盖半屏 |
| 碰撞 | 细长 line collision，长度约 150–170 px，不使用巨型方形 Hitbox |
| 命中频率 | `localNPCHitCooldown = 12–14` |
| 单次伤害 | 左键当前基础伤害 × 0.42–0.50；不暴击、不额外爆炸 |
| 效果 | 矛尖留短黑色 shader 环迹，少量黑色砂粒；每圈最多一次很弱的绿边缘闪烁 |

它的职责是贴身清怪与自保，不是第三种核爆。回旋期间不生成任何灵魂、裂隙、触手、爆炸；否则三种输入又会重新长成同一种“自动特效堆”。

建议文案语义如下（最终颜色标签可由本地化负责人调整）：


禁止继续使用“投矛扎入敌人体内并持续引发连锁爆炸”的表述，除非后续确实实现了插入目标和持续状态。文案必须和实际行为一一对应。

## 8. 验收标准

### 功能

- 左键三段顺序正确；停手超过 40 帧后回到第一段。
- 左键命中只出现一次即时范围爆炸，不出现裂隙、触手、追踪核心。
- 单独右键稳定打出 3 发，前两发每矛最多 3 个魂针，第三发为零个魂针。
- 第三发仅命中 NPC 时产生有伤害终爆；撞墙、超时没有伤害爆炸。
- 左键按住后按右键进入回旋；松开任一键立即停；单独右键绝不误进回旋。
- 切武器、死亡、被禁用物品、多人客户端离开时，所有 holdout 和魂针正常结束。

### 视觉

- 左键挥舞期间看不到黑色 GlowSpark/GlowSpark2 火花。
- 左键主视觉始终是矛尖的短黑色 shader 残像；黑色颗粒只作粒屑点缀。
- 普通左键命中能明确读出“碰到—爆开—结束”，屏幕上不留持续伤害实体。
- 前两投矛的灵魂从飞行路线附近出现，读起来像被矛划开的阴影，不像从地图外随机飞来的弹幕。
- 第三矛的爆炸明显大于前两矛，但不遮挡 Boss 本体、弹幕和玩家位置。

### 平衡与性能

- 任意时刻每名玩家最多存在 6 个本武器魂针；每枚前置投矛最多 3 个。
- 左键一次命中只生成 1 个爆炸投射物；第三发只生成 1 个终爆投射物。
- 不允许“命中后再生成会继续生成伤害投射物”的递归链。
- 在多人和高刷新率环境下，所有影响伤害的生成均由拥有者控制并同步；纯视觉粒子可本地化。

## 9. 给实现者的底线

这次改造的关键不是再加一层华丽效果，而是让每个效果都回答一个问题：它服务哪一种输入、哪一段动作、哪一个战术职责？

若一个效果不能让玩家更容易读懂“我现在在扫群、在点远处、还是在贴身自保”，就不要加入。冥蚀的黑色应该像矛尖划开光线后的余痕，而不是一场永不结束的自动深渊灾害。
