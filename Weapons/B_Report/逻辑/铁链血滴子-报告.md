# Terraria 链断头台 (Chain Guillotine) 实现机制分析报告

在 Terraria (和 tModLoader) 的源码中，**链断头台 (Chain Guillotine / Chain Guillotines)** 是一个设计非常经典且精致的武器。它在代码层面的实现主要依托于武器物品（Item）的配置、弹幕（Projectile）的 AI 状态机（AI Style 13 - Harpoon），以及在渲染端（Drawing）独有的**惯性弯曲物理拟真算法**。

以下是关于该武器核心技术实现的详细分析报告。

---

## 一、 武器与弹幕的基础属性

### 1. 物品配置 (ItemID: 3012 - ChainGuillotines)

## 二、 弹幕 AI 逻辑与生命周期机制

断头台弹幕的核心逻辑位于 [Projectile.cs](file:///D:/Documents/My%20Games/Terraria/拆解模组/tML%202024.04%E6%BA%90%E7%A0%81%E4%B8%8EExampleMod/tModLoader/Terraria/Projectile.cs#L18256-L18363) 的 `aiStyle == 13` 块中。其运行分为两个状态：**伸出状态 (Outward)** 和 **收回状态 (Returning)**。这两者通过 `ai[0]` 的值来标识。

### 1. 状态 0: 伸出阶段 (`ai[0] == 0f`)
- **帧更新加速 (`extraUpdates`)**:
  当弹幕处于伸出状态时，其 `extraUpdates = 1`。这意味着弹幕在游戏每 tick 中会更新 **2 次**。
  折合初始速度 `shootSpeed = 9`，实际飞出速度为 **$9 \times 2 = 18$ 像素/tick**（即每帧 18 像素）。
- **最大距离限制**:
  在每次更新时，代码计算弹幕中心与玩家中心的距离 $L$。
  - 对于链断头台 (`type == 481`)，最大距离设定为 **525 像素**。
  - 一旦 $L > 525\text{f}$，弹幕将状态机切换为收回状态：`ai[0] = 1f`，并开始执行返回逻辑。
  - 重力影响豁免：一般的鱼叉弹幕（如 Harpoon）在飞出 10 tick 后会受到重力下坠（`velocity.Y += 0.3f`），但断头台、石巨人拳套、链刀等武器在此处进行了类型过滤，将其计数器 `ai[1]` 限制在 8 以内，因此**断头台完全不受重力下坠影响**，弹道为绝对直线。

### 2. 状态 1: 收回阶段 (`ai[0] == 1f`)
- **触发条件**:
  - 飞出距离超过 525 像素。
  - 击中敌人（NPC 或 PVP 玩家），立刻在碰撞判定中被强行设为 `ai[0] = 1f` ([Projectile.cs:L11475](file:///D:/Documents/My%20Games/Terraria/拆解模组/tML%202024.04%E6%BA%90%E7%A0%81%E4%B8%8EExampleMod/tModLoader/Terraria/Projectile.cs#L11475))。
  - 撞击到实心方块墙壁，立刻强行设为 `ai[0] = 1f` ([Projectile.cs:L14917](file:///D:/Documents/My%20Games/Terraria/拆解模组/tML%202024.04%E6%BA%90%E7%A0%81%E4%B8%8EExampleMod/tModLoader/Terraria/Projectile.cs#L14917))。
- **运动规律**:
  - 开启无视物块碰撞：将 `tileCollide` 设为 `false`，确保在收回时能穿墙返回玩家身边。
  - **帧更新再次加速**: 处于返回状态时，`extraUpdates` 被提升为 **2**，这意味着弹幕每 tick 会更新 **3 次**！
  - 速度被强行重置为直接指向玩家，速度向量大小（模长）固定为 **20 像素/update**。
  - 结合 3 次更新/tick，实际返回速度高达 **$20 \times 3 = 60$ 像素/tick**（是飞出速度的 3.3 倍）。
- **销毁判定**:
  当弹幕收回到与玩家中心距离小于 **50 像素** 时，调用 `Kill()` 销毁自己。

### 3. 极速近战爆发机制（贴脸极速折返）
由于该 AI 特性，**链断头台拥有极强的近距离输出爆发能力**：
- 如果目标贴近玩家（例如距离 90 像素）：
  - 飞出时间：$90 / 18 = 5$ 帧。
  - 返回时间：$90 / 60 = 1.5$ 帧。
  - 弹幕的总生命周期只有约 7 帧，而武器的 `useTime` 为 14 帧。这使得弹幕能在下一发发射前早已安全折返。
- 配合玩家的近战攻速加成，可以在极近距离造成高密度的攻击，在极短时间内打出极高的 DPS。

## 三、 连接链条的渲染机制与物理弯曲算法

这是链断头台最具视觉魅力的地方。当断头台伸出时，它与玩家之间会有一条锁链相连。在代码中，这条锁链并不是物理系统中的刚体，而是由 `Main.DrawProj` 渲染端在**绘制每一帧时动态算出来的插值曲线**。

### 1. 链条贴图
锁链使用的材质贴图是 [TextureAssets.Chain40.Value](file:///D:/Documents/My%20Games/Terraria/拆解模组/tML%202024.04源码与ExampleMod/tModLoader/Terraria/Main.cs#L25014) (路径为 `Images/Chain40`)，这是一款专属的断头台黑铁色金属锁链贴图。

### 2. 连续覆盖绘制算法
在 [Main.cs:L24922-L25016](file:///D:/Documents/My%20Games/Terraria/拆解模组/tML%202024.04源码与ExampleMod/tModLoader/Terraria/Main.cs#L24922-L25016) 中，链条的绘制以 `while` 循环方式进行：
1. 算法起点设在断头台弹幕头部中心 `origin5`（根据飞出/收回状态，沿速度方向微调 4 像素）。
2. 计算 `origin5` 到玩家手持点（挂载中心 `mountedCenter`）的距离。
3. 如果距离大于 1.5 倍的贴图高度（`Chain40.Height() * 1.5`），则继续在当前 `origin5` 处绘制一段锁链。
4. 每画完一段，将起点 `origin5` 向玩家方向推进一个步长：
   $$\text{Step} = \text{Chain40.Height()} \times 0.85$$
   通过使用 `0.85` 的缩放因子，链条节与节之间会有 **15% 的重叠面积**，这使得在弹幕高速运动或发生弯曲时，锁链各节之间依然紧密相扣，不会出现视觉上的脱节和空洞。

### 3. 核心物理视觉：动态惯性下垂 (Dynamic Inertia Sag)
普通的链条弹幕（如鱼叉）在玩家移动时，链条呈一条绝对笔直的线，显得非常僵硬。而**链断头台特意实现了一套基于空气阻力和玩家惯性的动态弯曲插值算法**：
```csharp
if (num123 > (float)(TextureAssets.Chain40.Height() * 2)) { // 距离玩家一定距离的锁链节才应用弯曲
    for (int n = 0; n < 2; n++) {
        float num124 = 0.75f;
        float num125 = 1f;
        // 分别获取玩家 X 轴和 Y 轴的速度绝对值
        num125 = ((n != 0) ? Math.Abs(Main.player[proj.owner].velocity.Y) : Math.Abs(Main.player[proj.owner].velocity.X));
        if (num125 > 10f)
            num125 = 10f; // 限制速度贡献上限为 10

        num125 /= 10f; // 归一化为 0.0 ~ 1.0
        num124 *= num125;
        
        // 计算该节点到玩家的距离占比系数
        num125 = num123 / 80f;
        if (num125 > 1f)
            num125 = 1f;

        num124 *= num125; // num124 最终反映弯曲修正强度

        if (n == 0) {
            // 当玩家横向移动且弹幕在玩家同侧时，对 Y 轴步长增量进行缩减，强行制造惯性滞后的弧度
            if (Main.player[proj.owner].velocity.X < 0f && proj.Center.X < mountedCenter.X)
                y6 *= 1f - num124;

            if (Main.player[proj.owner].velocity.X > 0f && proj.Center.X > mountedCenter.X)
                y6 *= 1f - num124;
        }
        else {
            // 当玩家纵向移动（如坠落）且弹幕在玩家同侧时，对 X 轴步长增量进行缩减
            if (Main.player[proj.owner].velocity.Y < 0f && proj.Center.Y < mountedCenter.Y)
                x6 *= 1f - num124;

            if (Main.player[proj.owner].velocity.Y > 0f && proj.Center.Y > mountedCenter.Y)
                x6 *= 1f - num124;
        }
    }
}
```

#### 弯曲背后的几何原理：
1. **速度响应**：玩家跑动或坠落的速度越快（`velocity` 越大），链条偏角就越大，视觉上链条就像是被风吹弯了（落后于玩家身位）。
2. **距离平滑渐变**：
   - 靠近弹幕头部的锁链节（距离玩家远，`num123` 大，`num125 = num123 / 80f` 达到 1.0），弯曲修正强度 `num124` 达到最大值（最高可缩减 75% 的偏移量）。
   - 靠近玩家手部的锁链节（`num123` 小，逐渐归零），弯曲修正强度 `num124` 趋向于 0。
3. **视觉效果**：这种“渐变式”的偏移，把原本生硬的直线绘制变成了一条平滑的**拟贝塞尔曲线**。当玩家高速坠落时，锁链会呈现一条优美的弧线挂接在玩家手里，惯性动感十足。

## 五、 总结

链断头台的实现可视为 Terraria 弹幕系统中的杰作之一。它巧妙地做到了以下三点：
1. **双重速度机制**：伸出时 2 次更新，返回时 3 次更新（且速度为 20），创造了极速收回的干脆打击感；
2. **零阻碍回收**：收回阶段强行无视墙壁碰撞，防止武器丢失或回收卡顿；
3. **渲染端物理仿真**：摒弃复杂的刚体悬挂物理计算，直接在 `Main.DrawProj` 阶段根据玩家速度和锁链节点距离做插值衰减（**Inertia Sag** 惯性下垂），以极低的性能开销，达成了完美的绳索惯性曲率效果。
