# SHPC与亚利姆水晶配饰分类及描述语法报告

## 一、SHPC配饰的三大类

SHPC配饰当前已经形成了比较清楚的三类结构：`General`、`Skill`、`ChangeRight`。这三类不只是文件夹分类，也对应三种完全不同的玩家理解方式。

### 1. General：能源核心

代表物品：

- 废土级能源核心
- 永霜级能源核心
- 进化级能源核心
- 星流级能源核心

这一类是SHPC的纵向成长线。它们互相排斥，同一时间只应装备一个，效果以阶梯式基础强化为主。

核心特色：

- 提升SHPC本体伤害。
- 降低左键、右键魔力消耗。
- 增加左键装填容量。
- 提供停火回魔、魔力花自动喝药等资源循环能力。
- 高阶核心开始允许右键暴击、提供暴击率、提供无限魔力或弹药节省。

描述语法：

能源核心的描述应当像参数表，重点是让玩家快速判断这是第几阶、比上一阶强在哪里。

推荐顺序：

1. 先写SHPC伤害、暴击率等最核心数值。
2. 再写左键与右键的消耗变化。
3. 再写装填量、弹药节省。
4. 最后写资源循环或高阶特权。

例式：

```text
SHPC伤害+X%，魔法暴击率+X%
SHPC左键魔力消耗-X%，右键魔力消耗-X%
增加能量光球储罐，弹药装填量+X%
手持SHPC且停火时，快速恢复魔力
```

这类描述不适合写太多情绪语录。它的职责是建立“升级线”的秩序感。

### 2. Skill：功能芯片与战术模块

代表物品：

- 快充芯片
- 扩散芯片
- 火控芯片
- 飞升芯片
- 热量敏感器
- 矩阵充能屏障
- 全合一芯片组

这一类是SHPC的横向功能外挂。它们不一定形成升级线，而是给SHPC追加某一种战术能力。

核心特色：

- 快充芯片偏大招充能，但有生命回复惩罚。
- 扩散芯片偏伤害与右键热量强化攻击集中度。
- 火控芯片偏准星、锁定、追踪、自瞄。
- 飞升芯片偏移动能力与手持SHPC时的飞行时间。
- 热量敏感器偏右键热量机制，强化过热伤害与热量等级收益。
- 矩阵充能屏障偏防御，手持SHPC时生成护盾。
- 全合一芯片组汇总四种芯片能力，并移除部分负面效果。

描述语法：

功能芯片的描述要先交代“它管哪一块系统”，再交代具体数值或行为。它不需要像能源核心那样严格按阶梯写，而应突出功能身份。

推荐顺序：

1. 如果有常驻数值，第一行写常驻数值。
2. 如果必须手持SHPC，紧接着写“手持SHPC时”。
3. 对复杂效果使用多行短句，一行只放一个动作。
4. 如果有视觉隐藏、Shift展开、解锁前隐藏等特殊UI规则，必须写明。
5. 如果有负面作用，应与收益写在同一个tooltip里，不能藏起来。

例式：

```text
增加X%魔法伤害和X%魔法暴击率
手持SHPC时，右键强化攻击获得更强的集中度
```

或：

```text
手持SHPC时充能一层护盾
护盾血量为最大生命值的X%
受伤后延迟X秒开始充能，X秒充满
护盾存在时受到的防前伤害降低X%
```

全合一芯片组属于特殊情况。它的描述应保留两层：

- 简略描述：说明它拥有四芯片功能，按Shift展开。
- 完整描述：逐条列出每个芯片提供的效果。

### 3. ChangeRight：枪身改造部件

代表物品：

- 枪身改造部件-迫击
- 枪身改造部件-炮台
- 枪身改造部件-吸收
- 卡拉萨瓦模块

这一类是SHPC右键替换件。它们与能源核心、普通芯片不同，不是强化默认右键，而是把右键改造成另一种武器模式。因此它们必须互斥，同一时间只能装备一个。

核心特色：

- 迫击：右键变为迫击模式，发射爆炸炮弹并降下激光雨。
- 炮台：右键变为军用呼叫器，部署友军炮台。
- 吸收：右键变为弹幕吸收，复制敌方弹幕并释放友方分身。
- 卡拉萨瓦：右键变为蓄力炮，蓄力后释放高强度能量炮。

描述语法：

枪身改造的第一句必须是模式声明。

推荐顺序：

1. 第一行固定写“手持SHPC时右键改为X模式”。
2. 第二行写主要输入方式，例如按住、松开、点按。
3. 中间写核心输出、限制、容量、失败条件。
4. 最后一行可以放一句风格化短语。

例式：

```text
手持SHPC时右键改为吸收模式
最多吸收X发敌对弹幕
将它们复制一份并吸收在玩家周围
松开右键会将储存的友方分身向前直线连射出去
“图，伤，速，大小，无敌帧，花来”
```

这类描述允许比能源核心更有性格，因为它们本质上是在介绍一个新右键玩法。

## 二、SHPC描述总规则

SHPC配饰描述要遵守一个总原则：先告诉玩家它属于哪种系统，再告诉玩家它改变了什么。

推荐总规则：

- 能源核心：写阶梯参数，少写玩梗。
- 功能芯片：写功能身份，复杂效果拆行。
- 枪身改造：第一句必须声明右键替换模式。
- 涉及“手持SHPC时”的效果必须明确写出触发条件。
- 涉及负面效果、互斥、隐藏视觉、解锁条件的内容不能省略。
- 数值描述应尽量使用统一格式：`+X%`、`-X%`、`X秒`、`X发`。

## 三、亚利姆水晶配饰现状

亚利姆水晶配饰当前位于`Accssory/YC`，代码上已经分成两个文件夹：

- `Mainline`
- `Sideline`

现有主线文件夹内有五个：

- Alpha
- Delta
- Gamma
- Sigma
- Omega

现有旁支文件夹内有六个：

- Chi
- Phi
- Pi
- Psi
- Theta
- Upsilon

实际效果大致如下：

- Alpha：提高亚利姆水晶武器伤害。
- Chi：提供较小武器伤害加成。
- Delta：强化杀戮形态并缩短冷却。
- Gamma：提高棱镜无人机光弹速度。
- Sigma：无人机攻击形态额外发射机枪光弹。
- Omega：小幅提高伤害，并改善传奇技能充能。
- Phi：提高传奇技能充能，缩短冷却。
- Pi：强化重火力齐射，更频繁发射以太通量光线。
- Psi：无人机攻击形态额外发射机枪光弹。
- Theta：降低魔力消耗。
- Upsilon：小幅提高无人机光弹速度。

当前问题是：已有`Mainline`与`Sideline`的代码分类，但玩家侧描述还没有形成像SHPC那样稳定的语法。尤其是“武器伤害”这个说法偏宽，容易让人误会成近战、泛用、全伤害都被提高。

## 四、建议的亚利姆水晶新分类

亚利姆水晶配饰建议分为四类：

1. 主线核心：四级合成线，一个合成一个。
2. 刀刃旁支：强化左键、杀戮、近身绞杀节奏。
3. 棱镜舰阵旁支：强化右键无人机、光弹、重火力齐射。
4. 运转旁支：强化魔力循环、传奇技能充能与冷却。

### 1. 主线核心：四级合成线

建议四个主线为：

```text
Alpha -> Gamma -> Sigma -> Omega
```

不建议让Delta继续留在四级主线中。Delta的语义更像“杀戮形态专精”，适合归入刀刃旁支；Omega则天然适合当终阶。

四级主线定位：

#### Alpha：起源棱镜

定位：第一块基础调谐核心。

建议效果：

- 亚利姆水晶基础伤害小幅提高。
- 魔法伤害提高。
- 魔力消耗小幅降低。

建议描述：

```text
使用亚利姆水晶时，魔法伤害提高X%
亚利姆水晶基础伤害提高X%，魔力消耗小幅降低
不会提高近战伤害
```

#### Gamma：折射棱镜

定位：第二阶，开始强化发射节奏和弹速。

建议效果：

- 继承Alpha。
- 魔法伤害进一步提高。
- 亚利姆水晶光弹速度提高。
- 左键或右键的基础展开速度略微提高。

建议描述：

```text
继承Alpha的效果
使用亚利姆水晶时，魔法伤害进一步提高
棱镜光弹飞行速度提高，展开节奏略微加快
不会提高近战伤害
```

#### Sigma：集束棱镜

定位：第三阶，把多个小增益合成成稳定输出结构。

建议效果：

- 继承Gamma。
- 魔法伤害继续提高。
- 亚利姆水晶基础暴击率提高。
- 棱镜无人机或光弹获得额外发射单位。

建议描述：

```text
继承Gamma的效果
使用亚利姆水晶时，魔法伤害和亚利姆水晶暴击率提高
棱镜阵列会追加一次轻型折射攻击
不会提高近战伤害
```

#### Omega：终末棱镜

定位：第四阶终点，主线毕业核心。

建议效果：

- 继承Sigma。
- 魔法伤害达到主线最高加成。
- 亚利姆水晶基础伤害、暴击率、魔力效率综合提升。
- 传奇技能充能获得小幅改善，但不抢Phi的专精位置。

建议描述：

```text
继承Sigma的效果
使用亚利姆水晶时，魔法伤害大幅提高
亚利姆水晶基础伤害、暴击率和魔力效率提高
传奇技能充能略微加快
不会提高近战伤害
```

主线描述的关键是每一阶都必须写清楚：

- 它继承上一阶。
- 它提升魔法伤害。
- 它提升亚利姆水晶基础属性。
- 它不提升近战伤害。

这样可以避免“亚利姆水晶挥刃看起来像近战，所以玩家以为吃近战加成”的误解。

### 2. 刀刃旁支

建议成员：

- Delta
- Chi

定位：强化左键、杀戮、近身绞杀、刀刃节奏。

Delta适合做“杀戮形态专精”，继续强化现有杀戮伤害与冷却。Chi可以做更轻量的刀刃基础增幅，例如提高左键转盘稳定性、命中后的燃烧碎片数量或追踪火球质量。

描述语法：

```text
使用亚利姆水晶时，左键刀刃形态获得强化
杀戮形态伤害提高，冷却缩短
```

注意：如果旁支想强化左键，也应写“亚利姆水晶左键”或“刀刃形态”，不要写“近战伤害提高”。

### 3. 棱镜舰阵旁支

建议成员：

- Pi
- Psi
- Upsilon

定位：强化右键无人机、棱镜光弹、舰阵齐射。

Pi适合继续保留重火力齐射和以太通量光线。Psi适合做额外机枪光弹。Upsilon适合做弹速、追踪、弹幕连贯性。

描述语法：

```text
使用亚利姆水晶时，右键棱镜舰阵获得强化
无人机光弹速度提高，并额外发射一枚轻型光弹
```

这一类描述要避免太泛，应直接指出强化的是右键、无人机、光弹、齐射还是以太通量。

### 4. 运转旁支

建议成员：

- Phi
- Theta

定位：解决资源与传奇技能循环。

Phi继续负责传奇技能充能和冷却。Theta继续负责魔力消耗。两者可以不进主线，否则主线会变得过于臃肿。

描述语法：

```text
使用亚利姆水晶时，魔力消耗降低X%
传奇技能充能更快，冷却更短
```

这类描述要短，像运行效率说明，不要写成攻击模式说明。

## 五、亚利姆水晶描述总规则

亚利姆水晶配饰的描述建议采用以下统一语法：

### 1. 名称规则

保持：

```text
亚利姆水晶 - Alpha
```

或：

```text
暴君水晶 - Alpha
```

二者需要在最终本地化中统一。目前武器显示名是“新传奇 - 暴君水晶”，配饰显示名是“亚利姆水晶 - X”。如果后续要统一口径，建议改成“暴君水晶 - X”，这样更贴近当前武器名。

### 2. 主线描述规则

主线每一阶都应明确写“魔法伤害”，不要写“近战伤害”或“全伤害”。

推荐模板：

```text
继承上一阶亚利姆水晶核心的效果
使用亚利姆水晶时，魔法伤害提高X%
亚利姆水晶基础属性提高：伤害+X%，暴击率+X%，魔力消耗-X%
不会提高近战伤害
```

如果觉得“不会提高近战伤害”太直白，可以改成更自然的写法：

```text
这些加成只作用于亚利姆水晶与魔法伤害
```

### 3. 旁支描述规则

旁支不要写继承关系，直接写专精。

推荐模板：

```text
使用亚利姆水晶时，X形态获得强化
具体强化内容
```

例如：

```text
使用亚利姆水晶时，右键棱镜舰阵获得强化
无人机光弹速度提高，并额外发射一枚机枪光弹
```

### 4. 避免词

以下说法容易造成误解：

- “武器伤害提高”：不清楚是全局、亚利姆水晶专属，还是泛用武器。
- “伤害提高”：缺少对象。
- “近战伤害提高”：违背该系列定位。
- “全伤害提高”：会把它变成泛用饰品，而不是亚利姆水晶配饰。

推荐替换：

- “亚利姆水晶基础伤害提高”
- “使用亚利姆水晶时，魔法伤害提高”
- “亚利姆水晶右键阵列伤害提高”
- “亚利姆水晶左键刀刃形态获得强化”

## 六、推荐最终结构

```text
YC配饰
├─ 主线核心：Alpha -> Gamma -> Sigma -> Omega
│  ├─ 基础伤害
│  ├─ 魔法伤害
│  ├─ 暴击率
│  ├─ 魔力效率
│  └─ 少量传奇技能充能
├─ 刀刃旁支：Chi / Delta
│  ├─ 左键刀刃
│  ├─ 杀戮形态
│  └─ 近身绞杀节奏
├─ 棱镜舰阵旁支：Pi / Psi / Upsilon
│  ├─ 右键无人机
│  ├─ 棱镜光弹
│  ├─ 重火力齐射
│  └─ 以太通量光线
└─ 运转旁支：Phi / Theta
   ├─ 传奇技能充能
   ├─ 传奇技能冷却
   └─ 魔力消耗
```

这个结构的好处是：

- 主线只有四个，符合“一个合成一个”的升级线。
- 旁支保留创意空间，不会挤压主线。
- 魔法伤害和亚利姆水晶专属属性被明确绑定。
- Delta不再抢主线位置，而是成为杀戮专精。
- Omega作为终阶有明确仪式感。

## 七、结论

SHPC的分类已经比较成熟，可以作为亚利姆水晶配饰系统的参考：先分清纵向成长、横向功能、玩法替换，再决定描述语法。

亚利姆水晶建议不要完全照搬SHPC的三类，而应根据武器自身分成“主线核心、刀刃旁支、棱镜舰阵旁支、运转旁支”。主线采用`Alpha -> Gamma -> Sigma -> Omega`四级合成线，持续提升亚利姆水晶基础属性与魔法伤害，并明确不提升近战伤害。旁支则负责左键杀戮、右键舰阵、魔力与传奇技能循环。

这样写出来的物品描述会更有规矩：玩家一看名称知道希腊字母体系，一看第一句知道它属于主线还是旁支，一看数值知道它强化的是亚利姆水晶与魔法伤害，而不是泛用近战饰品。
