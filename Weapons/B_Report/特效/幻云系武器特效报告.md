# 幻云系武器特效报告

## 读取范围

本报告读取自本地 `CalamityMod` 源码，覆盖以下武器与配套弹幕：

- Alpha Draconis：`AlphaDraconis.cs`、`AlphaDraconisStar.cs`
- Galileo Gladius：`GalileoGladius.cs`、`GalileoGladiusProj.cs`、`GalileoGladiusThrown.cs`、`GalileosMoon.cs`
- Halley's Inferno：`HalleysInferno.cs`、`HalleysInfernoHoldout.cs`、`HalleysComet.cs`、`HalleysStarburst.cs`
- Vega：`Vega.cs`、`VegaProjectile.cs`、`VegaStar.cs`、`VegaSpark.cs`
- Crescent Moon：`CrescentMoon.cs`、`CrescentMoonFlail.cs`、`CrescentMoonProj.cs`

## 总体审美归纳

这组武器的共同视觉核心不是单纯的“蓝色粒子”，而是“星体武器”的完整语言：高亮星核、深蓝外焰、月牙或剑刃轮廓、拖尾、星座连线、脉冲环和短促爆闪。主色集中在 `SkyBlue`、`CadetBlue`、`DeepSkyBlue`、`DarkSlateBlue`、`Lavender`、白色，以及少量深蓝 `(69, 69, 200)`。Halley's Inferno 会额外使用粉、黄、绿、紫、白等随机星爆色，但基础弹道仍然是深蓝和冰蓝。

绘制方式上，它们大量使用加法混合、粒子替代实体贴图、PrimitiveRenderer 拖尾、shader 火焰轨迹、Bloom 粒子、Spark 粒子、GlowBlade、GlowMask、手绘链条段，以及“实际弹幕不可见，视觉由粒子承担”的做法。黑底发光素材应按加法光源处理，让黑色背景消失，只保留蓝白发光形体。

节奏上，这些武器很少把特效平均撒满全程，而是分层处理：发射瞬间有脉冲环或爆闪，飞行中有细长拖尾和星屑，命中或终段有粉尘、星爆、音效叠加。`extraUpdates` 和 `FinalExtraUpdate` 经常被用来让弹道更顺滑，同时控制粒子只在正确的更新帧生成。

## Alpha Draconis

Alpha Draconis 的视觉重点是从高处坠落的蓝色星弹。它的星弹使用 `extraUpdates = 4`、短弹幕实体、较长旧位置缓存和 PrimitiveRenderer 轨迹，形成高速、连续、很亮的星尾。

核心做法：

- 主色是 `CadetBlue`、`SkyBlue`、`DeepSkyBlue`，整体偏冷、透明、神秘。
- 飞行时使用 `ArsenalPlasmaDust`，死亡时使用像素化压扁尘 `SquashDustPixelated`。
- 本体绘制前先画 12 个环形偏移的发光残影，颜色透明度归零但 RGB 保留，靠加法混合产生柔光。
- 拖尾通过 `PrimitiveRenderer.RenderTrail` 绘制，shader 为 `CalamityMod:ImpFlameTrail`。
- 外层拖尾使用 `ScarletDevilStreak`，内核使用 `SylvestaffStreak`，宽度随 completion 和时间脉冲变化。
- 外层是更宽的蓝色火焰，内层是较窄的白蓝核心。

可借鉴点：

- 适合 LeonidProgenitor 的大流星、蓄力星弹、天降弹幕。
- 大型高速弹幕优先使用 PrimitiveRenderer 拖尾，而不是只靠普通 afterimage。
- 外宽内窄的双层拖尾非常适合表现“星云外焰 + 星核”。

## Galileo Gladius

Galileo Gladius 的审美更锋利，核心是蓝白光剑、星座连线和短促的星光节点。它不是铺满屏幕的粒子，而是把光集中在剑刃、刺击方向和玩家与飞剑之间的连接线上。

核心做法：

- 近战刺击使用 `GlowBlade` 材质叠加，颜色 `SkyBlue * 0.75`。
- 刺击过程中生成两列 `CustomSpark`，粒子材质是 `CalamityMod/Particles/BloomCircle`，拉伸成竖向光刺。
- 弹幕本体和 glow 图层都偏 `SkyBlue`，整体干净、透明、锋利。
- 投掷状态下，在玩家和飞剑之间绘制星座折线。
- 星座线由多个偏移节点组成，节点上生成 `BloomParticle` 和 `CustomSpark("Sparkle")`。
- 连线使用 `CalamityUtils.DrawLineBetter`，宽度和亮度按距离、脉冲强度变化。
- 爆发时叠加深蓝 `SparkParticle`、空心环形 `CustomSpark`、多个星体弹幕与强音效。

可借鉴点：

- 适合 LeonidProgenitor 的持握武器、右键锁定、牵引、反射或星链机制。
- 武器本体可以用 GlowBlade 作为“光刃层”，再叠普通贴图和 glow 图。
- 如果需要表现与目标、玩家、引力场之间的联系，星座连线比普通闪电更符合这套审美。

## Halley's Inferno

Halley's Inferno 是这组里最强的“枪械星爆”模板。普通射击是深蓝高速针束，右键星爆则变成彩色流星拖尾。它的视觉结构非常清楚：枪口蓄能、深蓝弹道、命中反馈、彩色星爆。

核心做法：

- 枪口附近使用 `GlowSparkParticle` 和随机星爆色，颜色包括 `HotPink`、`Yellow`、`LimeGreen`、`SkyBlue`、`Lavender`、`White`。
- 普通 `HalleysComet` 实体本身不可见，视觉由细长 `SparkParticle` 构成。
- 外层弹道是深蓝 `new Color(8, 35, 156)`，内层是浅蓝 `new Color(184, 215, 245)`。
- 发射早期生成 `DirectionalPulseRing`，颜色为 `Aqua` 和 `DodgerBlue`，制造枪口冲击环。
- 持枪本体绘制 24 个环形后坐力偏移，颜色是透明 `Chartreuse`，形成枪身周围的光晕。
- 星爆弹 `HalleysStarburst` 使用与 Alpha Draconis 相同的 PrimitiveRenderer 拖尾结构，但宽度更大，色彩由随机星爆色控制。
- 星爆飞行时持续生成 `BloomParticle` 和白色 `CustomSpark("Sparkle")`，死亡时补一圈 `GlowSparkParticle`。

可借鉴点：

- 适合 LeonidProgenitor 的高射速、连发、星爆充能、金属锭触发弹幕。
- 普通弹道可以做成“不可见弹幕 + 两层拉伸 Spark”的细蓝激光。
- 大招或特殊锭效果可以使用随机或指定星爆色，但锭附魔色应作为覆盖层，不要破坏蓝白星云基调。

## Vega

Vega 的视觉重点是投掷星体、命中后裂变，以及小型星屑自动飞散。它不像 Halley 那样有大枪口和粗轨迹，而是偏“星核破裂，碎星追踪”。

核心做法：

- 主投掷物使用 item 贴图，并通过 afterimage 与 `VegaGlow` glowmask 强化轮廓。
- 命中后生成 6 个子弹幕，部分为 `VegaStar`，部分为 `VegaSpark`。
- `VegaStar` 不绘制实体贴图，完全靠 `BloomParticle(Color.SkyBlue)` 和白色 `CustomSpark("Sparkle")` 表现。
- `VegaSpark` 使用深蓝 `SparkParticle(new Color(69, 69, 200))`，作为小型暗蓝星屑。
- 子弹幕先有短暂运动阶段，然后速度衰减，部分情况下进入追踪。
- 命中音效叠加多个音效，强化“星体碎裂”感。

可借鉴点：

- 适合 LeonidProgenitor 的命中裂变、碎星、反射后分裂、被动星屑追踪。
- 小型星屑可以不画实体，完全用 Bloom + Sparkle 或深蓝 Spark 粒子表现。
- 主弹幕保留清晰贴图，小弹幕转为粒子化，可以避免画面拥挤。

## Crescent Moon

Crescent Moon 是这组里最偏“武器形体”的模板：月牙、链条、环绕、释放、星爆。它的特效不是单一飞弹，而是围绕玩家的月相运动和释放后的月牙扩散。

核心做法：

- 主 flail 弹幕本体透明，PreDraw 手动绘制链条、柄、头部各段。
- 持续蓄力或环绕时，会按计时发射 `CrescentMoonProj`。
- `CrescentMoonProj` 本体不正常绘制，而是通过 `BloomParticle(Color.SkyBlue)` 和 `CustomSpark` 使用自身月牙贴图表现。
- 月牙弹幕有蓝色光照，后段可以追踪。
- 星爆释放时生成 `ScorpiusConstellation`，扩大判定，并使用 `CustomPulse` 播放 `ShatteredExplosion` 材质。
- 星爆颜色使用 `SkyBlue` 和 `DeepSkyBlue`，再叠加大量 109、111、132 dust。
- 蓄力星爆期间会操纵两个 StarburstEntity 围绕 flail 旋转，形成仪式感。

可借鉴点：

- 适合 LeonidProgenitor 的右键蓄力、引力场、环绕星体、最终爆发。
- 月牙类贴图可以作为 `CustomSpark` 材质使用，让贴图变成粒子而不是普通实体。
- 链条、轨道、环绕点这类结构应手动绘制，稳定性会比靠 dust 堆叠更高。

## 共同视觉语法

### 颜色

基础色应以蓝白星光为主：

- 星核：白色、浅蓝、`SkyBlue`
- 外焰：`CadetBlue`、`DeepSkyBlue`、`DodgerBlue`
- 暗部：`DarkSlateBlue`、深蓝 `(69, 69, 200)`、`new Color(8, 35, 156)`
- 点缀：`Lavender`、少量黄绿粉等星爆色

LeonidProgenitor 的锭附魔配色可以作为覆盖层或局部主题色，但底层的发光、拖尾、星屑仍应保留这套蓝白星云审美。

### 形状

优先使用以下形状语言：

- 星核圆点和 Bloom 节点
- 细长流星拖尾
- 双层拖尾，宽蓝外焰加窄白核心
- 月牙贴图粒子
- 星座折线
- 枪口或爆点脉冲环
- 光刃材质
- 环绕玩家或目标的星体轨道

### 绘制

推荐优先级：

1. 大型高速弹幕：PrimitiveRenderer + `ImpFlameTrail` + 双层 trail texture。
2. 小型星屑：不绘制实体，使用 `BloomParticle`、`SparkParticle`、`CustomSpark("Sparkle")`。
3. 武器本体：普通贴图 + glowmask + 加法偏移光晕。
4. 连接关系：星座折线节点，而不是普通直线光束。
5. 爆发瞬间：`DirectionalPulseRing`、`CustomPulse`、集中 dust、强音效。

## 对 LeonidProgenitor 的落地建议

LeonidProgenitor 如果要贴近这批武器的审美，应避免只改颜色或只堆 dust。更合适的方向是把每一种攻击拆成明确的视觉层：

- 普通弹幕：蓝白星核 + 深蓝细尾 + 少量 Sparkle。
- 大流星：PrimitiveRenderer 双层拖尾，外层宽蓝，内层白蓝。
- 近身或持握动作：GlowBlade 或 glowmask 叠加，突出武器轮廓。
- 右键、引力、锁定：使用星座线、环绕星点、节点 Bloom。
- 命中裂变：Vega 式粒子化碎星，主弹清楚，小弹轻巧。
- 爆发：Halley 和 Crescent Moon 式脉冲环、CustomPulse、集中 dust、强音效。
- 锭附魔：锭颜色只作为“效果主题层”，底层仍保持蓝白星云、月牙、星座、流星这一套共同语言。

这套视觉真正重要的是“星体结构感”：玩家应能一眼看出弹幕来自星云、月相、流星和星座，而不是普通蓝色魔法弹。
