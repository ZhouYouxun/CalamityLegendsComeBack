# 反器材狙击步枪：设计文档

> 状态：玩法定稿草案，供后续数值测试与美术设计使用。
>
> 核心定位：雅利姆军队反器材狙击兵的旧制式装备。它服务于远距离、单目标、精确处决；每一发子弹都应当有明确的来路、目标和落点。

---

## 1. 设计边界

1. 这是一把栓动反器材狙击步枪。左键保持直接、可靠，攻击节奏由重后坐力与拉栓动作塑造。
2. 右键提供持续架枪和渐进式瞄准。满稳定度的一发子弹拥有整把武器最远的有效射程与最高的处决效率。
3. `.408` 子弹永远沿直线飞行，不追踪、不分裂、不弹射、不产生清图爆炸。
4. 伤害主要集中在首个被命中的目标。反器材感通过高速、破甲、命中后的内部碎裂来表现。
5. 滑步负责脱离危险与创造射击窗口；它不承担持续输出任务。
6. 独立枪托攻击、手枪变形、自动切换武器均不纳入第一版设计。

武器的强度来自“把一发子弹送到正确的位置”，不来自替玩家寻找目标或覆盖大量敌人。

---

## 2. 基础物品与弹药

| 项目 | 方案 |
|---|---|
| 基础伤害 | `168` 远程伤害，作为首版测试起点。 |
| 左键间隔 | `60` 帧（1 秒）。攻速只能略微改善后半段复位手感，不能将它变成高速连射武器。 |
| 弹药 | 消耗普通子弹；所有被消耗的子弹均转化为 `.408 CheyTac` 专用弹。原弹药的追踪、分裂、爆炸等额外行为不继承。 |
| 弹药外观 | 黑色弹尖、暗银弹体、极细的银白曳光尾迹。枪口闪光短促且明亮，随后留下少量烟尘。 |
| 基础有效射程 | 约 `220` 格；在常规 Boss 战的可见战场中足够远，仍能看见弹体飞行。 |
| 地形交互 | 命中第一个实心物块即停止，产生火花与金属撞击声；不破坏地形。 |

### `.408` 专用弹的基础规则

- 命中次数：`1`。子弹伤害首个有效敌人后消失，敌人穿透次数为 `0`。
- 弹速：高到足以让一屏距离只留下极短飞行时间；弹体仍需可见，不能做成命中扫描光线。
- 破甲：基础射击无视约 `35%` 防御。该数值须在实际灾厄 Boss 防御环境中测试。
- 最大生命值真实伤害：不采用。它会让低级敌人变成固定次数处决目标，也会让 Boss 机制独立于武器成长。
- 弹道：水平飞行，视觉上维持近乎平直的高速轨迹；不加入任何自动修正与追踪。

## 3. 输入与状态

### 3.1 左键：直接射击

左键按下立刻发射，不蓄力、不需要松键、不存在预先存放在枪口的待发子弹。

一次射击应当清楚表现以下过程：

1. 枪口闪光、弹体离膛、曳光线出现。
2. 人物与枪身向后抬起，提供有分量但不用于位移滥用的后坐力。
3. 拉栓、抛壳、枪身回正。
4. `60` 帧后允许下一发。

普通左键是移动战和紧急反击的可靠选择。它拥有基础射程、基础破甲与完整的单目标命中效果。

### 3.2 右键：渐进架枪

右键长按进入“架枪瞄准”。这不是另一把武器，也不消耗弹药；它是一段把玩家换成更高精度的风险—回报过程。

| 阶段 | 建议时长 | 画面与行动 | 左键结果 |
|---|---:|---|---|
| 抵肩 | `0–15` 帧 | 枪托抵肩，准星收紧，移动速度略降。 | 发射普通 `.408` 子弹，并立刻退出瞄准。 |
| 展距 | `16–60` 帧 | 视野平滑扩大，镜头逐渐拉远；移动速度降至约 `60%`。 | 发射普通 `.408` 子弹，并立刻退出瞄准。 |
| 满稳定度 | `61` 帧起 | 视野扩大至最高级别，呼吸与镜片反光稳定；移动速度降至约 `25%`。 | 发射一枚“稳定射击”子弹，并立刻退出瞄准。 |

松开右键只会收起瞄准，不会射击。

### 3.3 稳定射击

满稳定度后按左键发射的稳定射击是武器的招牌动作：

- 有效射程提高到约 `440` 格。
- 弹速提高，曳光更长、更细，命中感更接近真正的超远程精确射击。
- 无视防御提升至约 `55%`。
- 伤害提高至基础武器伤害的 `150%`。
- 依旧只命中一个目标；不追踪、不穿透敌人、不产生范围爆炸。

这使左键与右键形成明确分工：左键保持战斗流动，右键要求站位、视野与耐心。满稳定度并非额外蓄力攻击，它是架枪完成后获得的一次精确发射窗口。

## 4. 命中语言与视觉

### 4.1 命中表现

`.408` 的命中需要有“重物贯入”的感觉：

- 命中敌人时先出现针状闪白，再出现向内收束的暗红/暗银冲击圈。
- 稳定射击额外留下一条从枪口延伸至目标的短暂直线曳光，随后才播放命中冲击。
- 命中方块只出现火星、金属粉屑与一声闷响，不生成大范围特效。
- 不使用自动锁定圈、跟踪箭头或会替玩家修正弹道的视觉提示。

### 4.2 内部碎裂

后续的“金属射流”保留其质感，改为严格的单目标表现：

- 子弹命中后，可在 `4–6` 帧后对同一目标触发一次内部碎裂。
- 内部碎裂伤害建议从主弹的 `25%–35%` 起测。
- 特效从命中点向目标内部收束，避免形成身后扇形喷射与群体伤害。

这让武器保有反器材弹的内部破坏感，同时守住单体处决的使命。

## 5. 滑步狙击

### 5.1 定义

滑步狙击是一段定向战术脱离动作。它在手感上承担冲刺功能，在画面上必须明确呈现为低姿态、倾斜身体、拖出短暂尘迹的滑步。

建议使用独立的“特殊技能键”触发，避免挤占左右键功能。

### 5.2 肉山后初版

- 触发时锁定当前方向，滑步过程中不可转向。
- 持续约 `0.25` 秒，可穿过敌人与弹幕。
- 不能在滑步中射击。
- 第一次滑步结束后开启 `2` 秒续接窗口，最多连续使用 `2` 次。
- 两次机会耗尽后进入 `30` 秒冷却。
- 每次滑步结束后，下一枚满稳定度的子弹获得“滑步射击”：伤害额外提高 `40%`，内部碎裂效果加强。

它创造的是“避开攻击—重新架枪—打出决定性一发”的循环。滑步不应成为无间隔位移工具。

### 5.3 神吞后升级：维度滑步

维度滑步缩短位移的起手与收束，使动作更像一次瞬间跨越；保留不可转向、两段续接和后续强化射击。滑步结束时自动完成一次拉栓动作，方便玩家快速进入下一次满稳定度瞄准。

不加入对沿途敌人的切割伤害，也不赋予小怪秒杀。这个阶段仍然服务于单个高价值目标。

## 6. 枪托、手枪与近距离处理

### 最终决定：第一版不制作独立枪托攻击

理由很直接：

- 近距离时左键的一发 `.408` 已经具备更高风险、更高收益与更强的身份感。
- 右键已经承担瞄准状态；再塞入短按右键枪托会增加判定歧义。
- 特殊技能键由滑步占用，滑步也已经解决了狙击手最重要的近身问题：脱离。
- 手枪切换会破坏武器的节奏和视觉主题。

为朋友保留一个未来扩展口：若实测确认近身生存空间不足，可让滑步结束时对贴身敌人播放一次无伤害的枪托推开动画，仅提供极短推离与视觉反馈。该方案不进入第一版，也不构成近战输出循环。

## 7. 进度强化总表

| 游戏节点 | 名称 | 效果与目的 |
|---|---|---|
| Boss 前 | `.408 CheyTac` 专用弹 | 高速、单目标、基础破甲；建立反器材射击手感。 |
| 克苏鲁之眼后 | 装甲断裂 | 直接命中使目标短时间防御降低，效果不叠加；为后续精准连射创造窗口。 |
| 克脑 / 世吞后 | 内部碎裂 | 获得同目标的延迟碎裂伤害，完全删除锥形金属射流与后方群伤。 |
| 肉山后 | 滑步狙击 | 两段定向脱离，滑步后的满稳定度射击强化。 |
| 任意机械王后 | 后坐力补偿枪机 | 稳定射击命中后，下一次拉栓恢复更快；保持栓动节奏，提升连续精准输出。 |
| 世纪之花后 | 弹道校准 | 在短时间内连续命中同一目标可积累校准数据；第三次满稳定度命中消耗数据并造成显著增伤。打空或更换目标会失去数据。弹体永远不追踪。 |
| 月亮领主后 | 过量暴击转化 | 超过 `100%` 的暴击率按 `1:1` 转为额外暴击伤害。 |
| 亵渎守卫后 | 核心裂解 | 暴击时对同一目标追加一次不可暴击的内部冲击；用单点爆发取代六枚追踪小弹。 |
| 神明吞噬者后 | 维度滑步 | 滑步动作升级，结束时完成拉栓，保持单体猎杀节奏。 |
| 星流 / 终灾后 | 玛瑙爆炸弹匣 | 奇数发为标记弹，附着目标或方块最多 `5` 秒；偶数发命中同一目标或经过方块标记的小判定区时引爆。爆炸伤害为武器攻击力的 `200%`，不可暴击，范围极小。 |

### 弹道校准的可读性

校准数据只显示为目标身上的淡色测距刻线与镜片中的距离数字。它记录的是玩家已经打中的目标，不改变下一颗子弹的方向，确保“命中”仍然完全由玩家完成。

## 8. 故事与 Tooltip

### 故事基调

该枪曾装备于雅利姆军队的反器材狙击兵。射手被部署在战线外缘，负责让掩体、重甲、运输构件和大型威胁失去继续推进的能力。它经历过太多次远距离射击，枪身上留下的痕迹比所属部队的番号更加完整。

### 常规 Tooltip 建议

```text
消耗子弹
左键：立刻发射一枚高速 `.408` 专用弹
右键：持续架枪瞄准，视野将逐步扩大
满稳定度时左键发射射程最远、破甲最强的稳定射击
子弹只命中首个目标，不会追踪或产生范围爆炸
肉山后获得特殊技能：滑步狙击
[按住 Shift 查看传说]
```

## 9. 首轮体验验收

完成第一版后，玩家应当能自然感受到以下体验：

1. 左键立刻能救场；右键提供一个清晰而有风险的远距离处决姿态。
2. 视野扩大、移动减速、镜片稳定与满稳定度提示共同告诉玩家何时可以打出最强的一发。
3. 每枚子弹都有可追踪的直线轨迹，命中目标后干净地结束；画面中没有追踪弹、扇形群伤或自动清怪。
4. 滑步把玩家从危险位置送出，再把战斗带回架枪和命中的节奏。
5. 到终局时，玛瑙弹匣让两发子弹形成精确的“标记—引爆”处决连段，整把枪始终保持单目标身份。
