# 庄方宜宠物贴图规格

本文档记录当前实现读取各贴图的切分方式。所有贴图均位于 `新版贴图/` 子目录下，均为单列、纵向多帧，帧序号从 0 开始（代码里用 `DrawVerticalFrame` 按 `texture.Height / rows` 均分截取）。

## 普通形态（未开启天理真和）

| 贴图 | 帧数 | 用途 |
| --- | --- | --- |
| 庄方宜宠物_待机.png | 8 | 待机本体 |
| 庄方宜宠物_移动.png | 8 | 移动本体 |
| 庄方宜宠物_飞行.png | 7 | 飞行本体 |
| 庄方宜宠物_攻击.png | 7 | 攻击本体，弱/强攻击共用同一套动画，按 `actionTimer` 单次播放（不循环） |
| 庄方宜宠物_尾巴.png | 8 | 尾巴，待机/移动/飞行/攻击各状态下持续独立循环 |
| 庄方宜宠物_眨眼.png | 5 | 眨眼叠加层，仅在眨眼窗口内叠加绘制在本体之上 |
