## 一、基类与代理机制概述

原版 Terraria 的近战武器仅能围绕玩家轴心做简单的扇形摆动，这极大地限制了武器贴图大小、挥舞物理轨迹、多段连击和特效的自由绘制。
本项目继承灾厄模组的设计思路，采用**弹幕代理机制**（即手持弹幕 Holdout Projectile）：
* **肢体接管（Composite Arm System）**：通过 `player.SetCompositeArmFront` 强行旋转玩家手臂以对齐武器握柄。
* **碰撞盒重映射**：不再依靠弹幕默认判定框，而是通过 `Colliding` 钩子或基类 `ModifyDamageHitbox` 将贴图长度、宽度旋转到对应的角位移方向，形成线形或精密的定向矩形判定区。
* **完全手绘（Custom PreDraw）**：隐藏原版弹幕绘制，在 `PreDraw` 中利用轴心偏置（`SpriteOrigin`）、半圆刀光贴图（Smear/Swoosh）、Shader 残影和多层叠加（BlendState.Additive）实现大气的动效。

## 二、核心物理与动作模型通用机制

在自定义大剑的挥击中，大部分武器使用以下三种插值曲线控制武器旋转轨迹：
1. **指数级缓动插值（ExpInOut Easing）**：
   $$\text{Progress} = \text{Easing}(t / T_{max})$$
   在 C# 中由 `CalamityUtils.ExpInOutEasing(progress, 1)` 实现，能在挥击的中段产生爆发性角位移速度，两端平滑过渡。
2. **Piecewise（分段插值）与 PolyOut/PolyIn**：
   将动作割裂为明显的“前摇积蓄（Windup）”与“猛烈斩击（Strike）”。前摇通常占总时长的 $20\% \sim 66\%$，角速度极慢且向后拉伸；斩击瞬间爆发至最大角速度，扫过整个扇形区。
3. **线性匀速循环旋转（Linear Spin）**：
   不带加速，一般用于 $360^\circ$ 或 $1080^\circ$ 的无死角旋风斩，角速度恒定为：
   $$\omega = \pm \frac{2\pi \cdot N}{T_{max}}$$

## 三、武器深度技术剖析

### 1. 青霆剑 (AzureThunder)
* **关联弹幕类**：`AzureThunderSwingHoldout`
* **基类类型**：`BaseCustomUseStyleProjectile`

#### A. 核心物理数学参数
* **基础缩放比例**：$1.0\text{f}$。由于旧资源与新贴图尺寸不同，在绘制时使用比例补偿：
  $$\text{HoldoutDrawScale} = \frac{158\text{f}}{80\text{f}} = 1.975\text{f}$$
* **手持轴心原点 (SpriteOrigin)**：`new Vector2(0f, 78f)`
* **握柄在玩家手部锚定偏移 (GripOrigin)**：`new Vector2(0f, 172f / HoldoutDrawScale)` 即 $Y$ 轴偏置补偿。
* **基础判定盒参数**：
  * 剑刃射程 (Outset)：$118\text{f}$
  * 判定矩形大小 (HitboxSize)：$170\text{f} \times 170\text{f}$
  * 判定偏转角 (HitboxRotationOffset)：$-45^\circ$（$-\frac{\pi}{4}\text{ rad}$）
* **挥击时长与帧表**：
  * 普通模式（4段连击）：单段持续时间 $T_{max} = 45$ 帧。前摇时间 $T_{windup} = 30$ 帧，斩击时间 $T_{swing} = 15$ 帧。
  * 天理真和模式（Harmony Active，3段连击）：单段持续时间 $T_{max} = 30$ 帧。前摇时间 $T_{windup} = 10$ 帧，斩击时间 $T_{swing} = 20$ 帧。
  * 段间隙冷却（Gap Timer）：$5$ 帧。

#### B. 挥舞轨迹与转向逻辑
* **前摇阶段 (Timer < ImpactFrame)**：
  * `CanHit = false`。
  * 玩家可以朝鼠标方向微调，每帧调用 `UpdateLockedAimFromMouse()` 刷新 `Owner.direction`。
  * 武器偏角缓慢差值偏向向后蓄力方向：
    $$\theta_{offset} \to 120^\circ \times \text{swingDirection} \times \text{Owner.direction} \times \text{WindupAngleScale}$$
    其中 `GetWindupAngleScale()` 在连段的首发时为 $1.35$（拉伸蓄力角），后续连段为 $1.0$。
* **斩击阶段 (Timer >= ImpactFrame)**：
  * 强行锁定 `FlipAsSword` 翻转状态，防止在中途越过中轴线时贴图跳变。
  * 角度从起点 $150^\circ \times \text{dir} \times \text{owner.dir}$ 过渡到终点 $120^\circ \times -\text{dir} \times \text{owner.dir}$，总挥击跨度为 **$270^\circ$**。
  * 使用指数级缓动：`CalamityUtils.ExpInOutEasing(swingProgress, 1)`。
* **伤害窗口**：`swingProgress` 介于 $0.4$ 到 $0.7$ 之间（即斩击时长的 $40\% \sim 70\%$ 处）。

#### C. 弹幕派生与打击判定
* 命中免疫：本地免疫机制 `localNPCHitCooldown = 16`。
* **招式派生逻辑**：
  * **普通 Stage 0**：斩击点生成 $3$ 颗自动寻敌的蔚蓝光球 `SpawnLightOrbs`。
  * **普通 Stage 1**：生成 $2$ 把自动刺向鼠标的飞剑，并在鼠标位置引发 $0.4$ 倍倍率落雷。
  * **普通 Stage 2**：生成 $4$ 把飞剑，并在鼠标位置引发 $0.5$ 倍倍率落雷。
  * **普通 Stage 3（终结段）**：根据犽戎进度和场上存活的地剑数量，在前方依次生成 $3 \sim 9$ 道递推的强力落雷。
  * **真和 Stage 0/1**：在前方生成由 $4 \sim 5$ 道平行雷柱构成的雷幕。
  * **真和 Stage 2（真和终结）**：从天而降一把劈向鼠标处的巍峨天理巨剑，产生大范围震屏与冲击波。

#### D. 视觉效果与粒子绘制
* **PreDraw 重写**：
  * 绘制发光刀光贴图 `CalamityMod/Particles/SemiCircularSmearSwipe`，采用加算模式 `BlendState.Additive`。
  * 基于 `HoldoutOutlineHelper.DrawSolidOutline` 绘制外包边，包边颜色为亮蓝色（`new Color(0, 180, 255)`）。
  * 在刀刃挥舞轨迹的高频帧中，衍生 `GlowSparkParticle` 和 `HeavySmokeParticle`。

#### E. 核心 C# 代码段示范
```csharp
// 斩击角速度与位移公式计算
float swingTime = stageTimer - stageDuration / 3f;
float swingTimeMax = stageDuration - stageDuration / 3f;
float swingProgress = MathHelper.Clamp(swingTime / swingTimeMax, 0f, 1f);

RotationOffset = MathHelper.Lerp(
    RotationOffset,
    MathHelper.ToRadians(MathHelper.Lerp(
        150f * Projectile.ai[1] * Owner.direction,
        120f * -Projectile.ai[1] * Owner.direction,
        CalamityUtils.ExpInOutEasing(swingProgress, 1))),
    0.2f);
```

### 2. 凤凰刃 (PhoenixBlade)
* **关联弹幕类**：`PhoenixBladeHoldout`
* **基类类型**：`BaseCustomUseStyleProjectile`

#### A. 核心物理数学参数
* **基础缩放比例**：$1.25\text{f}$。
* **手持轴心原点 (SpriteOrigin)**：`new Vector2(0f, 106f)`
* **判定方法**：完全自定义线段碰撞 `Collision.CheckAABBvLineCollision`。
  * 剑尖距离 (Reach)：$135\text{f} \times \text{scale}$
  * 碰撞检测宽度：$18\text{f} \times \text{scale}$
* **使用时长**：由武器本身使用时间决定（默认 $T_{max} = 22$ 帧），可受攻速缩放。

#### B. 挥舞轨迹与转向逻辑
* **旋转机制**：
  * 没有前摇和蓄力拉后，直接执行全周 $360^\circ$ 旋风斩。
  * 每帧角位移计算：
    $$\theta_{spin} = \theta_{spin} + \frac{2\pi}{T_{max}} \times \text{Owner.direction}$$
  * 角度自动收束到 $-\pi \sim \pi$（`MathHelper.WrapAngle`）。
* **左右转向**：
  * 实时判断转动方向：`facing = Math.Cos(spinAngle) >= 0 ? 1 : -1`。
  * 强行调用 `Owner.ChangeDir(facing)`，使得玩家角色随着大剑旋风斩的轨迹高频转身。
* **伤害窗口**：全时间常驻。只要在挥舞动画内皆能造成伤害，利用 `localNPCHitCooldown = 12` 实现极高频的连击。

#### C. 弹幕派生与打击判定
* **OnHitNPC 特效**：
  * 命中任何 NPC 时，在目标处生成一个毁灭性爆炸弹幕 `FuckYou`（ID对应凤凰印记爆炸）。
  * 该爆炸弹幕在本地生成，半径为 $132\text{f}$，伤害为大剑面板的 $90\%$。

#### D. 视觉效果与粒子绘制
* **外包边绘制**：使用 `HoldoutOutlineHelper.DrawSolidOutline` 生成橙黄色包边（`Color(255, 95, 36)`）。
* **火焰刀光**：在 PreDraw 中，以加算模式叠加绘制灾厄特制贴图 `"CalamityMod/Particles/CircularSmearFire2"`。
  * 绘制缩放：$\text{smearScale} = \frac{135\text{f} \cdot \text{scale}}{78\text{f}}$
  * 贴图方向根据玩家朝向反转：如果 `Owner.direction < 0`，角度修正 $+180^\circ$。
* **粒子逸散**：在剑刃末端（通过三角函数算得）高频抛射 `DustID.SolarFlare`（带切向初始速度）与 `DustID.Torch` 粒子。

#### E. 核心 C# 代码段示范
```csharp
// 360度无限自转物理
float spinRate = MathHelper.TwoPi / useAnim * owner.direction;
spinAngle += spinRate;
spinAngle = MathHelper.WrapAngle(spinAngle);

Projectile.rotation = spinAngle + MathHelper.PiOver4;
Projectile.Center = owner.MountedCenter + spinAngle.ToRotationVector2() * Projectile.scale * 10f;
```

### 3. 新执法者 (TheNewEnforcer)
* **关联弹幕类**：`TheNewEnforcerHoldOut`
* **基类类型**：`BaseCustomUseStyleProjectile`

#### A. 核心物理数学参数
* **基础缩放比例**：$1.35\text{f}$。
* **手持轴心原点 (SpriteOrigin)**：`new Vector2(0f, 100f)`
* **基础判定盒参数**：
  * 线碰撞长度：$226\text{f}$
  * 碰撞检测宽度：$36\text{f} \times \text{scale}$
  * 替代碰撞矩形：Outset $125\text{f}$，Size $190\text{f} \times 190\text{f}$
* **连击与帧表**：
  * 单段总长为武器使用时间（默认 $T_{max} = 32$ 帧）。
  * 蓄力前摇占 $2/3$ 时长（$0 \sim 21$ 帧）。
  * 斩击挥砍占 $1/3$ 时长（$22 \sim 32$ 帧）。

#### B. 挥舞轨迹与转向逻辑
* **蓄力期 (AnimationProgress < useAnim / 1.5f)**：
  * `CanHit = false`。
  * 武器向朝向的反方向过度蓄力，偏角向后拉拽。利用后拉曲线加入回弹表现（`windupOverpull`，最高增加 $35\%$ 蓄力偏角）：
    $$\theta_{offset} \to 120^\circ \times \text{ai[1]} \times \text{Owner.direction} \times (1 + \text{OverpullProgress} \times 0.35)$$
  * 蓄力时剑身微微放大（`baseScale * 1.02f`）。
* **斩击期 (AnimationProgress >= useAnim / 1.5f)**：
  * 使用 `CalamityUtils.ExpInOutEasing` 进行跨度为 **$270^\circ$** 的狂暴下劈或逆斩。
  * 起始角度为 $150^\circ \times \text{ai[1]} \times \text{dir}$，结束角度为 $120^\circ \times -\text{ai[1]} \times \text{dir}$。
  * 剑身在击中瞬间大幅增幅（配合正弦铃形曲线 `bell = Sin(progress * Pi)` 最大放大至 $1.36$ 倍）：
    $$\text{Scale} = \text{baseScale} \times \text{Lerp}(1.02\text{f}, 1.36\text{f}, \text{bell})$$
* **转向判定**：在挥砍瞬间和后摇时，角色朝向与斩击冲量反向强行对齐，但前摇时完全根据鼠标位置转向。
* **伤害窗口**：`swingProgress` 的 $40\% \sim 70\%$ 之间。

#### C. 弹幕派生与打击判定
* **命中结算**：局部免伤单次结算（`localNPCHitCooldown = -1`），即每次挥刀对同一目标仅击中一次。
* **弹幕齐射机制 (FireEssenceVolley)**：
  * 在斩击进行到 $40\%$ 且尚未发射时，朝剑尖的法线方向呈扇形向外喷吐 $7$ 枚“星河净化之炎”。
  * 净化之炎自动搜寻周围 $4400\text{f}$ 范围内的敌对目标。
  * 命中敌人施加灾厄神级Dot **施法重创 / 恶魔之火 (DemonicFlames)**。

#### D. 视觉效果与粒子绘制
* **星河渐变外包边**：
  在 PreDraw 中通过正弦时间差值在青色（`Color.Aqua`）与粉紫色（`Color.Magenta`）之间动态渐变，形成宇宙般斑斓的包边流光特效：
  $$\text{GalaxyColor} = \text{Lerp}(\text{Aqua}, \text{Magenta}, \sin(\text{GlobalTime} \times 6\text{f}) \times 0.5 + 0.5)$$
* **粒子特效**：挥舞时在剑尖生成大量的宇宙星河屑尘。

#### E. 核心 C# 代码段示范
```csharp
// 分段蓄力与爆破斩击过渡
if (AnimationProgress < useAnim / 1.5f)
{
    float windupOverpull = 1f + Utils.GetLerpValue(useAnim * 0.8f, useAnim, Animation, true) * 0.35f;
    float targetOffset = 120f * Projectile.ai[1] * owner.direction * windupOverpull;
    RotationOffset = MathHelper.Lerp(RotationOffset, MathHelper.ToRadians(targetOffset), 0.2f);
}
else
{
    float strikeProgress = (AnimationProgress - useAnim / 3f) / (useAnim - useAnim / 3f);
    float easedSwing = CalamityUtils.ExpInOutEasing(MathHelper.Clamp(strikeProgress, 0f, 1f), 1);
    RotationOffset = MathHelper.Lerp(RotationOffset, MathHelper.ToRadians(MathHelper.Lerp(150f * Projectile.ai[1] * owner.direction, 120f * -Projectile.ai[1] * owner.direction, easedSwing)), 0.2f);
}
```

### 4. 涡流海皇尊爵剑 (BrinyBaron)
* **关联弹幕类**：`BrinyBaron_LeftClick_Swing`
* **基类类型**：`BaseCustomUseStyleProjectile`

#### A. 核心物理数学参数
* **基础缩放比例**：基于 `BB_Balance.GetLeftClickScale()`（默认约为 $1.15\text{f}$）。
* **手持轴心原点 (SpriteOrigin)**：`new Vector2(0f, 102f)`
* **判定盒子参数**：

  * Size：`BB_Balance.LeftClickCoreHitboxSize`（旧版 $132\text{f} \times 132\text{f}$）
* **连击成长机制 (Growth Stages)**：
  * **第一阶段 (默认形态)**：只有单段普劈。
  * **第二阶段**：解锁 $3$ 段连斩。
  * **第三阶段（终结态）**：解锁 $4$ 段完美连斩，第 $4$ 段具备超大挥舞弧度与海潮剑气爆破。

#### B. 挥舞轨迹与转向逻辑
* **时值分配**：前摇时间占总时间的 $1/3$（`useAnim / 3`），挥砍斩击占后 $2/3$。
* **普通挥击弧度**：
  * 前摇时，武器在鼠标指向的一侧后拉收刀，偏置角趋向 $-45^\circ \times \text{ai[1]} \times \text{dir}$。
  * 斩击时，采用指数级差值从 $-45^\circ$ 顺/逆时针疯狂扫过 **$450^\circ$**（达 $1.25$ 圈）至 $405^\circ \times -\text{ai[1]} \times \text{dir}$。
* **右键突进悬停旋风斩 (Right Spin Active)**：
  * 长按右击进入特制旋转态。忽略普劈，角色向前方突进，武器化为在胸前飞速旋转的水晶护盾。
  * 突进速度恒定为 $14.5\text{f}$，旋风斩每 $12$ 帧触发一次 `SpawnRightSpinShuriken`，向四周散射跟踪水流飞镖。
  * 转动量：右键姿态下每帧角位移固定为 $30^\circ$（匀速）。

#### C. 弹幕派生与打击判定
* **海汐剑气派生表**：
  * **SeafoamBlade（海沫斩）**：在挥洒进度至 $30\%$ 时，发射一枚贯穿直线的海沫气刃弹幕。
  * **FormalWave（潮汐波）**：Stage 3 终结斩发射快速的水漩涡弹幕。
* 命中施加 **潮湿 (Wet)** 与 **盐水腐蚀** 状态。

#### D. 视觉效果与粒子绘制
* **水雾残影**：PreDraw 中采用特殊的多采样机制绘制 $16$ 帧的刀尖历史轨迹点，调用 Exo 弧形刀光渲染。
* **高亮水沫粒子**：在挥砍线段上，释放亮蓝色 `GlowOrbParticle` 与 `DustID.Water` 烟雾。

### 5. 暴君水晶 - 左击大剑 (YharimsCrystal)
* **关联弹幕类**：`YC_LeftBladeSwing`
* **基类类型**：`BaseCustomUseStyleProjectile`

#### A. 核心物理数学参数
* **基础缩放比例**：受暴君水晶能量进度倍乘补偿，约 $1.45\text{f}$。
* **手持轴心原点 (SpriteOrigin)**：`new Vector2(0f, 186f)`
* **判定盒子参数**：
  * 综合直径：$186 + 102 = 288\text{f}$
  * Outset：$size \times 0.85\text{f} = 244.8\text{f}$
  * 替代线段碰撞范围：$270\text{f} \times (1 + \text{bladeFade} \times 0.6) \times \text{scale}$
* **魔力攻速联动**：
  $$\text{useAnim} = \text{Clamp}(42\text{f} / \text{MagicSpeed}, 12\text{f}, 42\text{f})$$
  大剑挥舞时长随玩家的**魔法攻速**变化而平滑变化。

#### B. 挥舞轨迹与转向逻辑
* **待机追踪状态 (Holding = true)**：
  * 处于充能等待挥舞态，剑身常驻。
  * 剑尖平滑朝向鼠标方向，夹角为鼠标指向的 $+45^\circ$。
  * 若 $3$ 秒内无左键输入（`idleTimer >= 180`），弹幕进入淡出毁灭状态。
* **旋转斩击状态**：
  * 单次点击或连击时触发全周 **$360^\circ$** 斩击。
  * 旋转公式：
    $$\theta_{offset} = \theta_{start} + 2\pi \cdot \text{Progress} \cdot \text{ai[1]}$$
  * 斩击期间锁定玩家朝向，禁止高频抖动。
* **右键蓄力重投掷 (ThrowBlade)**：
  * 长按右击 $1$ 秒（$60$ 帧），剑身旋转冻结（角动量降为 $0$），手臂向后偏斜 $70^\circ$ 蓄力。
  * 蓄力满时朝鼠标方向爆射出去，转化为飞行巨剑弹幕（伤害乘算 $1.85$ 倍）。

#### C. 弹幕派生与打击判定
* **烈焰环绕 (SpawnSpinFlame)**：
  * 在挥砍期间，每隔 $7$ 帧在巨剑划过的轨迹边缘生成一枚暴君烈焰，该烈焰会环绕玩家形成保护光圈，随后刺向周围怪物。

#### D. 视觉效果与粒子绘制
* **晶耀粒子光流**：
  在巨剑挥舞时，剑刃受魔能升华影响，不断向外炸裂出金黄色 `GlowSparkParticle`、暗橙色 `CustomSpark` 与纯白色 `GenericSparkle` 粒子，火花横飞。
* **残影**：PreDraw 中沿 $360^\circ$ 轨迹重画多达 $20$ 层低透明度发光剑刃。

#### E. 核心 C# 代码段示范
```csharp
// 魔法速度加成下的360度大圆舞
float progress = CalamityUtils.ExpInOutEasing(time / timeMax, 1);
float spinAngle = MathHelper.TwoPi * progress * Projectile.ai[1];
RotationOffset = swingStartRotation + spinAngle;

if (time >= (int)(timeMax * 0.2f) && time < (int)(timeMax * 0.9f))
    CanHit = true;
```

### 6. 庇护之刃 (AegisBlade)

#### A. 核心物理数学参数

## 五、完全重构与从零实现指南

当你需要重构或从零编写本报告中列出的任何一把武器时，请遵循以下核心开发步骤：

### 步骤 1：构建动作与时间线控制
以 **青霆剑 (AzureThunder)** 为例，声明全局状态机变量：
* `comboIndex`：记录当前招式阶段。
* `stageTimer`：当前段的帧数计数器。
* `stageDuration`：本招式需要的总时长。
* 在弹幕的 `AI()` 方法中更新 `stageTimer`，一旦 `stageTimer >= stageDuration`，则重置计时器并增加 `comboIndex` 以进入下一击（若松开左键，则执行 `Kill()`）。

### 步骤 2：应用插值公式控制旋转与缩放
1. 声明 `RotationOffset` 与 `Projectile.rotation`。
2. 前摇时，使 `RotationOffset` 缓慢对齐至蓄力初始偏角。
3. 斩击时，通过 `CalamityUtils.ExpInOutEasing` 或 `EaseInOutExp` 将斩击进度 $t \in [0, 1]$ 转换成角度插值系数，直接乘算总角位移量（例如，盖尔大剑的 $234^\circ$），并在中段（$40\% \sim 70\%$）时使 `CanHit = true` 打开伤害。
4. 如需打击感反馈，通过正弦函数计算缩放因子，使大剑在斩击正中时膨胀 $1.2 \sim 1.35$ 倍。

### 步骤 3：重写 PreDraw 视觉系统
1. 在 `PreDraw` 钩子中，首先使用 `Main.spriteBatch.EnterShaderRegion(BlendState.Additive)` 进入加算绘制状态。
2. 绘制大剑划过的扇形刀光切片（Smear），缩放比例设定为：
   $$\text{SmearScale} = \frac{\text{武器实际长度} \cdot \text{scale}}{\text{Smear贴图半径}}$$
3. 使用 `HoldoutOutlineHelper` 绘制对应颜色的武器发光包边。
4. 退出加算，绘制武器实体，轴心设为 `SpriteOrigin` 对应的握柄处坐标。

### 步骤 4：处理判定与粒子衍生
1. 如果是超长武器（如凤凰刃、盖尔大剑），必须在 `Colliding` 钩子中重写为**线碰撞检测**：
   ```csharp
   Vector2 start = Owner.MountedCenter;
   Vector2 end = Owner.MountedCenter + Projectile.rotation.ToRotationVector2() * BladeReach * scale;
   return Collision.CheckAABBvLineCollision(targetHitbox.TopLeft(), targetHitbox.Size(), start, end, HitboxWidth * scale, ref collisionPoint);
   ```
2. 每一个物理击中帧，根据计算出的剑尖/剑刃局部坐标衍生特定的 `GlowSparkParticle` 或带有切线方向初始速度的 `Dust`。
