# 裂变风格闪电效果实现设计报告

这篇报告旨在指导你如何在自己的 Terraria 模组中，实现一个与救赎模组（Mod of Redemption）中“特斯拉线圈”和“鹰冠标枪”**类似但截然不同**的电弧特效。

外人一看会觉得“这闪电效果很棒，有类似的电弧感”，但一眼就能分辨出这是一种**完全独立的、具有裂变感的新型电弧**。

---

## 1. 核心创意：什么是“裂变风格闪电”？

*   **救赎模组的闪电（对比）**：是**单线折线电弧**。它只是一条扭曲的折线，连接起点和终点（就像一根扭曲的电线）。
*   **裂变风格闪电（我们）**：是**树状分叉电弧**。闪电在从起点传导到终点的过程中，在每个弯折点都有概率像细胞分裂或玻璃裂纹一样，**分叉出更细小、更微弱的次级闪电**，向四周发散并快速熄灭。

这会让你的闪电看起来不仅是在“导电”，而是在“撕裂空气”或“蔓延裂开”，视觉张力极大。

---

## 2. 核心算法逻辑（通俗版说明）

要实现这个效果，你的代码需要做三件事：**找点、分叉、画线**。

### 第一步：连起主干（主电弧折点）
不要画直线。假设起点是 $A$，终点是 $B$：
1. 把 $AB$ 之间平均分成例如 5 段。
2. 每一个分段的点，都往旁边随机偏移几像素（偏移方向垂直于 $AB$ 连线）。
3. 把这些点连起来，就得到了一条扭曲的主电弧。

### 第二步：分裂次级分支（裂变分叉）
在生成主电弧的折点时，每经过一个折点，就“抛一次硬币”（例如有 20% 的概率触发分叉）：
1. 如果触发分叉，就从当前折点开始，向外延伸出一条较短的折线。
2. 分叉的方向应该偏向两侧（比如偏离主电弧方向 30~45 度）。
3. 分叉电弧的段数要少（比如只有 2 段），长度要短，颜色要更淡。

### 第三步：把线画出来（绘制渲染）
我们不用写复杂的着色器（Shader）。直接使用 Terraria 原版的**粉尘粒子（Dust）**或者**拉伸图片**在点与点之间进行连线：
*   **推荐粉尘**：使用 `DustID.Electric`（原版青蓝色电流）或 `DustID.WitherLightning`（紫色闪电）。
*   在每个折点之间，用循环（如每次前进 4 像素）生成粒子，把它们连成线。

## 3. tModLoader 极简代码模板

你可以直接把下面的工具类代码引入到你的模组中。它是一个纯粹的代码模板，不依赖任何第三方库。

```csharp
using Microsoft.Xna.Framework;
using System.Collections.Generic;
using Terraria;
using Terraria.ID;

namespace CalamityLegendsComeBack.Effects
{
    public static class FissionLightning
    {
        /// <summary>
        /// 在两点之间绘制一条带分叉裂变效果的电弧
        /// </summary>
        /// <param name="start">起点</param>
        /// <param name="end">终点</param>
        /// <param name="dustType">使用的粉尘ID（默认使用蓝白电弧粉尘）</param>
        public static void DrawFissionLightning(Vector2 start, Vector2 end, int dustType = DustID.Electric)
        {
            // 1. 生成主干折点
            List<Vector2> mainBranch = GenerateSegmentPoints(start, end, segmentCount: 6, deviation: 25f);
            
            // 2. 绘制主干电弧
            DrawPointsWithDust(mainBranch, dustType, dustScale: 1.2f);

            // 3. 在折点上判定是否生成分叉
            for (int i = 1; i < mainBranch.Count - 1; i++)
            {
                // 30% 概率产生裂变分叉
                if (Main.rand.NextFloat() < 0.3f)
                {
                    Vector2 forkStart = mainBranch[i];
                    
                    // 计算当前主干的行进方向
                    Vector2 direction = mainBranch[i + 1] - mainBranch[i];
                    
                    // 随机向左或向右偏转 45 度左右
                    float angleOffset = Main.rand.NextBool() ? MathHelper.ToRadians(45) : MathHelper.ToRadians(-45);
                    Vector2 forkDirection = direction.RotatedBy(angleOffset);
                    
                    // 分叉长度为主干的一半左右
                    Vector2 forkEnd = forkStart + forkDirection * 0.5f;

                    // 生成分叉折点（分段更少，偏差更小）
                    List<Vector2> subBranch = GenerateSegmentPoints(forkStart, forkEnd, segmentCount: 3, deviation: 10f);
                    
                    // 绘制分叉（使用较小的粒子大小，显得更细）
                    DrawPointsWithDust(subBranch, dustType, dustScale: 0.7f);
                }
            }
        }

        // 内部工具：生成两点之间的折线点集
        private static List<Vector2> GenerateSegmentPoints(Vector2 start, Vector2 end, int segmentCount, float deviation)
        {
            List<Vector2> points = new List<Vector2>();
            points.Add(start);

            Vector2 diff = end - start;
            Vector2 normal = new Vector2(-diff.Y, diff.X); // 获取垂直于前进方向的法线
            normal.Normalize();

            for (int i = 1; i < segmentCount; i++)
            {
                float progress = i / (float)segmentCount;
                // 线性插值位置
                Vector2 basePos = Vector2.Lerp(start, end, progress);
                
                // 随机偏移（越靠近两端偏移越小）
                float offsetScale = MathF.Sin(progress * MathF.PI);
                float randOffset = Main.rand.NextFloat(-deviation, deviation) * offsetScale;

                points.Add(basePos + normal * randOffset);
            }

            points.Add(end);
            return points;
        }

        // 内部工具：用粒子在折点间连线
        private static void DrawPointsWithDust(List<Vector2> points, int dustType, float dustScale)
        {
            for (int i = 0; i < points.Count - 1; i++)
            {
                Vector2 start = points[i];
                Vector2 end = points[i + 1];
                
                float distance = Vector2.Distance(start, end);
                Vector2 direction = (end - start) / distance;

                // 每隔 6 像素铺设一个粉尘，连成实线
                for (float d = 0; d < distance; d += 6f)
                {
                    Vector2 spawnPos = start + direction * d;
                    Dust dust = Dust.NewDustPerfect(spawnPos, dustType, Vector2.Zero, newColor: Color.White, Scale: dustScale);
                    dust.noGravity = true;
                }
            }
        }
    }
}
```

## 4. 如何在武器中触发它？

比如你做了一把枪或者一把法杖，你想让它在子弹击中怪物时，从天空中劈下一道裂变电弧。你只需要在你的子弹弹幕类（Projectile）的 `OnKill` 方法中这样写：

```csharp
public override void OnKill(int timeLeft)
{
    // 获取击中点
    Vector2 impactPoint = Projectile.Center;
    
    // 闪电的起点设在上方 500 像素
    Vector2 skyPoint = impactPoint - new Vector2(0, 500);

    // 产生3条略微不同的裂变闪电叠在一起，增加层次感
    for (int i = 0; i < 3; i++)
    {
        FissionLightning.DrawFissionLightning(skyPoint, impactPoint, DustID.Electric);
    }
}
```

## 5. 效果评估

这个方案的闪电不仅保留了**闪电应有的折线质感**，而且通过**裂变分支**（Sub-branches），在视觉上模拟出了真实的静电分叉效果。相比于原版和救赎中平铺直叙的电线闪电，这更像一棵“倒挂在空中的枯树枝”，质感上更上一层楼，且代码实现轻量，不存在联机卡顿问题。
