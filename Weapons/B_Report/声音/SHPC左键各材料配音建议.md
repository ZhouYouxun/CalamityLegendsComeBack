# SHPC左键各材料配音建议

本报告覆盖 `Weapons/SHPC/Effects` 中当前注册的 41 种左键弹药材料。每种材料给出 3 个推荐音效，按推荐程度从高到低排列。

路径说明：

- `CalamityMod/Sounds/...`：CalamityMod 音效，按 `SoundStyle` 路径写法，不含扩展名。
- `CalamityLegendsComeBack/Sound/...`：本项目音效，按 `SoundStyle` 路径写法，不含扩展名。
- `SoundID.xxx`：原版 Terraria 音效 ID，可参考官方 Wiki 的声音 ID 页面：<https://terraria.wiki.gg/zh/wiki/%E5%A3%B0%E9%9F%B3_ID>。

## 总体建议

- 如果只想统一左键开火声，不做多阶段细分，优先采用每项的第 1 推荐。
- 如果某个材料本身会在命中或消失时额外生成爆炸、激光或追踪体，第 2、3 推荐更适合作为命中、爆炸、补发弹幕或蓄力提示声。
- 对高频材料，建议优先使用短促的 `SoundID` 或短 Calamity 音效；对低频终局材料，可以使用项目里的重型枪械、轨道炮、反坦克炮类音效。
