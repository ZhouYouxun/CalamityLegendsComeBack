# 如何让这个扭曲效果走这种扭曲的曲线进入一个弹幕内部

这份笔记记录的是旧版 `DarksunFragmentEclipseBolt` 的运动模型：小弹幕不是直线飞向目标，而是沿着一条逐渐收缩的螺旋弧线，被“拽进”另一个弹幕的核心。

## 适用场景

- 想表现“被吸入”“被吞噬”“被折叠进中心”的视觉。
- 目标是一个持续存在的主弹幕，而不是 NPC。
- 小弹幕可以只负责视觉，也可以在飞行途中保留伤害判定。

## 必要状态

小弹幕需要保存三个关键值：

```csharp
private Vector2 startPosition;
private Vector2 targetPosition;
private float initialDistance;
private float initialAngle;
```

含义：

- `startPosition`：小弹幕出生的位置。
- `targetPosition`：要钻入的目标弹幕中心。
- `initialDistance`：出生点到目标中心的初始距离。
- `initialAngle`：出生点相对目标中心的初始角度。

初始化时写：

```csharp
startPosition = Projectile.Center;
targetPosition = GetParentCenter();

Vector2 offset = startPosition - targetPosition;
initialDistance = Math.Max(offset.Length(), 12f);
initialAngle = offset.ToRotation();
```

## 核心公式

每帧先算进度：

```csharp
float completion = 1f - Projectile.timeLeft / (float)actualLifetime;
completion = MathHelper.Clamp(completion, 0f, 1f);
```

然后让半径逐渐缩小、角度持续旋转：

```csharp
float spinDirection = Projectile.ai[1] == 0f
    ? (Projectile.identity % 2 == 0 ? 1f : -1f)
    : Math.Sign(Projectile.ai[1]);

float spiralTurns = MathHelper.Lerp(
    0.6f,
    1.0f,
    Utils.GetLerpValue(240f, 420f, initialDistance, true));

float currentRadius = MathHelper.Lerp(initialDistance, 0f, completion);
float currentAngle = initialAngle + spinDirection * MathHelper.TwoPi * spiralTurns * completion;
Vector2 point = targetPosition + currentAngle.ToRotationVector2() * currentRadius;
```

最后把弹幕直接放到这个点上，并用位移差伪造速度：

```csharp
Vector2 previous = Projectile.Center;
Projectile.Center = point;
Projectile.velocity = point - previous;

if (Projectile.velocity.LengthSquared() > 0.001f)
    Projectile.rotation = Projectile.velocity.ToRotation();
```

这就是“扭曲曲线”的关键：它不是普通 homing，也不是贝塞尔曲线，而是极坐标里的半径收缩和角度旋转叠加。

## 消失条件

飞到目标中心附近时杀掉小弹幕：

```csharp
if (currentRadius < 12f || !ParentIsActive())
    Projectile.Kill();
```

如果目标弹幕会移动，可以每帧刷新：

```csharp
targetPosition = GetParentCenter();
```

这样曲线会持续朝目标当前中心收束。如果目标基本静止，曲线会更干净。

## 参数怎么调

- `spiralTurns` 越大，绕得越夸张。
- `actualLifetime` 越短，吸入越快。
- `initialDistance` 越远，曲线越明显。
- `spinDirection` 可以用 `Projectile.identity` 做交错，让多个小弹幕一半顺时针、一半逆时针。

推荐范围：

```csharp
float spiralTurns = 0.45f; // 轻微弯曲
float spiralTurns = 0.8f;  // 明显吸入
float spiralTurns = 1.2f;  // 强烈扭曲
```

## 最小可复用版本

```csharp
float completion = 1f - Projectile.timeLeft / (float)actualLifetime;
completion = MathHelper.Clamp(completion, 0f, 1f);

float spinDirection = Projectile.identity % 2 == 0 ? 1f : -1f;
float currentRadius = MathHelper.Lerp(initialDistance, 0f, completion);
float currentAngle = initialAngle + spinDirection * MathHelper.TwoPi * 0.8f * completion;

Vector2 previous = Projectile.Center;
Vector2 point = target.Center + currentAngle.ToRotationVector2() * currentRadius;
Projectile.Center = point;
Projectile.velocity = point - previous;

if (currentRadius < 12f || !target.active)
    Projectile.Kill();
```

这套写法的视觉重点是“路径由公式控制”，所以不要再叠加强追踪惯性，否则曲线会变脏。
