# 自定义角色皮肤覆盖系统报告
> 目标：让玩家取特定名字（或点击按钮）后，游戏完全用你自己的一套贴图渲染角色，绕开泰拉瑞亚原版的肤色/发色/性别系统。

---

## 一、核心原理

泰拉瑞亚渲染玩家时，分三个装备槽决定贴图：
- `Player.head`（头部/头盔）
- `Player.body`（躯干/护甲）
- `Player.legs`（腿部/护腿）

这三个字段的值是**装备贴图 ID**，不是物品 ID。
tModLoader 的 `EquipLoader.AddEquipTexture` 允许你注册一套贴图，**不绑定任何物品**，只拿到一个 ID。
然后在运行时强制把这三个字段改成你的 ID，同时用 `ArmorIDs.Player.Sets` 系列把原始皮肤层全部遮掉，
游戏就只渲染你的贴图，完全看不到原版肤色/发色。

---

## 二、需要准备的贴图

### 2.1 三张主体装备贴图（必须）

| 文件名（你自己命名） | 对应槽位 | 用途 |
|---|---|---|
| `MyCharHead.png` | Head | 头部（含发型、脸） |
| `MyCharBody.png` | Body | 躯干+手臂 |
| `MyCharLegs.png` | Legs | 腿部 |

**格式要求（帧动画精灵表）：**

- **宽度固定 40 px**
- **每帧高度固定 56 px**
- 垂直排列，帧数按照泰拉瑞亚原版动画帧数：
  - Head：20 帧（高 1120 px）
  - Body：20 帧（高 1120 px）
  - Legs：20 帧（高 1120 px）
- 参考原版贴图位置（解包后）：
  `Content/Images/Armor_Head_0.png` / `Armor_Body_0.png` / `Armor_Legs_0.png`
- 背景透明（PNG alpha 通道）

> **注意**：这三张贴图走的是"装备覆盖"路线，游戏会自动按 `Player.bodyFrame` 切帧、自动左右翻转、自动处理重力翻转。你只需要画好帧动画即可，不需要手动处理方向。

### 2.2 可选：自定义身体 DrawLayer 贴图

如果你的角色体型/比例与泰拉瑞亚原版不同（比如伊蕾娜 mod 里的 `身体部分.png` 是 40×56 的单帧，用 `PlayerDrawLayer` 手动绘制），
可以额外准备一张整体身体图，用 `PlayerDrawLayer` 完全接管躯干渲染（见第四节）。

### 2.3 音效（可选）
受伤音、死亡音、特殊互动音，放在 `Sounds/` 目录，用 `SoundStyle` 调用。

## 三、最小实现（仅靠名字触发，无 UI 按钮）

### 3.1 目录结构

```
你的Mod/
├── MyMod.cs                        ← Mod 主类，Load() 里注册贴图
├── MyCharModPlayer.cs              ← ModPlayer，负责触发 + 覆盖逻辑
└── Items/Armors/MyChar/
    ├── MyCharHead.png              ← 头部贴图
    ├── MyCharBody.png              ← 躯干贴图
    └── MyCharLegs.png              ← 腿部贴图
```

### 3.2 Mod 主类：注册装备贴图

```csharp
// MyMod.cs
using Terraria.ModLoader;

public class MyMod : Mod
{
    public override void Load()
    {
        // 第一个参数：本 Mod 实例
        // 第二个参数：贴图路径（相对 Mod 根目录，不含扩展名）
        // 第三个参数：装备类型
        // 第四个参数：null = 不绑定物品（纯贴图槽）
        // 第五个参数：这套贴图的"名字"，用来之后 GetEquipSlot 取 ID
        // 第六个参数：null = 用默认 EquipTexture
        EquipLoader.AddEquipTexture(this, "MyMod/Items/Armors/MyChar/MyCharHead", EquipType.Head, null, "MyChar", null);
        EquipLoader.AddEquipTexture(this, "MyMod/Items/Armors/MyChar/MyCharBody", EquipType.Body, null, "MyChar", null);
        EquipLoader.AddEquipTexture(this, "MyMod/Items/Armors/MyChar/MyCharLegs", EquipType.Legs, null, "MyChar", null);
    }
}
```

> **关键**：`"MyChar"` 这个名字三个槽位必须一致，之后用这个名字取 ID。

### 3.3 ModPlayer：触发 + 覆盖

```csharp
// MyCharModPlayer.cs
using Terraria;
using Terraria.DataStructures;
using Terraria.GameContent.Creative;
using Terraria.ModLoader;
using Microsoft.Xna.Framework;
using Terraria.ID;

public class MyCharModPlayer : ModPlayer
{
    // 是否处于"自定义角色"模式
    public bool IsMyChar = false;

    // ---- 1. 根据名字触发 ----
    public override void OnEnterWorld(Player player)
    {
        if (player.name == "你的角色名" || player.name == "AnotherName")
        {
            IsMyChar = true;
        }
    }

    // ---- 2. 存读档（让模式跨存档保持）----
    public override void SaveData(TagCompound tag)
    {
        tag["IsMyChar"] = IsMyChar;
    }
    public override void LoadData(TagCompound tag)
    {
        IsMyChar = tag.GetBool("IsMyChar");
    }

    // ---- 3. FrameEffects：每帧强制替换装备槽 ID ----
    // 这里改的是"逻辑层"，影响游戏内部状态
    public override void FrameEffects()
    {
        if (!IsMyChar) return;

        int slotHead = EquipLoader.GetEquipSlot(Mod, "MyChar", EquipType.Head);
        int slotBody = EquipLoader.GetEquipSlot(Mod, "MyChar", EquipType.Body);
        int slotLegs = EquipLoader.GetEquipSlot(Mod, "MyChar", EquipType.Legs);

        Player.head = slotHead;
        Player.body = slotBody;
        Player.legs = slotLegs;
    }

    // ---- 4. DrawEffects：每帧强制替换绘制信息 + 隐藏原版皮肤 ----
    // 这里改的是"渲染层"，影响实际显示
    public override void DrawEffects(PlayerDrawSet drawInfo, ref float r, ref float g, ref float b, ref float a, ref bool fullBright)
    {
        if (!IsMyChar) return;

        int slotHead = EquipLoader.GetEquipSlot(Mod, "MyChar", EquipType.Head);
        int slotBody = EquipLoader.GetEquipSlot(Mod, "MyChar", EquipType.Body);
        int slotLegs = EquipLoader.GetEquipSlot(Mod, "MyChar", EquipType.Legs);

        // 替换绘制信息里的装备 ID
        drawInfo.drawPlayer.head = slotHead;
        drawInfo.drawPlayer.body = slotBody;
        drawInfo.drawPlayer.legs = slotLegs;

        // 隐藏原版皮肤层（这是关键！）
        ArmorIDs.Head.Sets.DrawHead[slotHead]           = false; // 不额外渲染"头盔外显"层
        ArmorIDs.Body.Sets.HidesTopSkin[slotBody]       = true;  // 隐藏上半身原皮肤
        ArmorIDs.Body.Sets.HidesArms[slotBody]          = true;  // 隐藏手臂原皮肤
        ArmorIDs.Legs.Sets.HidesBottomSkin[slotLegs]    = true;  // 隐藏下半身原皮肤

        // 让游戏把角色当女性渲染（影响部分动作帧），可选
        Player.Male = false;
    }
}
```

> **为什么 FrameEffects 和 DrawEffects 都要改？**
> `FrameEffects` 是游戏更新逻辑阶段，影响动画帧计算、装备效果判断。
> `DrawEffects` 是渲染阶段，影响实际绘制。两处都改才能保证逻辑和显示一致。

## 四、进阶：用 PlayerDrawLayer 完全接管躯干渲染

如果你的角色**体型和原版不一样**，或者需要特殊的坐姿/特殊状态贴图，
单靠替换装备槽不够灵活，可以额外写一个 `PlayerDrawLayer`，
在指定的渲染层（比如"皮肤层和护腿层之间"）插入你自己的绘制逻辑。

```csharp
// MyCharBodyLayer.cs
using Microsoft.Xna.Framework;
using Microsoft.Xna.Framework.Graphics;
using ReLogic.Content;
using Terraria;
using Terraria.DataStructures;
using Terraria.ModLoader;

public class MyCharBodyLayer : PlayerDrawLayer
{
    private static Asset<Texture2D> BodyTexture;

    // 控制这个 Layer 是否显示
    public override bool GetDefaultVisibility(PlayerDrawSet drawInfo)
    {
        return drawInfo.drawPlayer.GetModPlayer<MyCharModPlayer>().IsMyChar
               && !drawInfo.drawPlayer.invis;
    }

    // 插入位置：在原版"皮肤"层之后，"护腿"层之前
    public override Position GetDefaultPosition()
    {
        return new Between(PlayerDrawLayers.Skin, PlayerDrawLayers.Leggings);
    }

    // 实际绘制
    protected override void Draw(ref PlayerDrawSet drawInfo)
    {
        // 计算屏幕位置
        Vector2 pos = drawInfo.Position.ToFloor() - Main.screenPosition;
        pos += new Vector2(10f, 18f); // 根据你的贴图调整偏移量
        pos += new Vector2(0f, drawInfo.drawPlayer.HeightOffsetVisual + drawInfo.drawPlayer.HeightOffsetHitboxCenter);

        // 左右朝向
        SpriteEffects se = drawInfo.drawPlayer.direction < 0 ? SpriteEffects.FlipHorizontally : SpriteEffects.None;

        // 切帧（用玩家的 bodyFrame.Y 对应动画帧）
        int frame = drawInfo.drawPlayer.bodyFrame.Y;
        Rectangle sourceRect = new Rectangle(0, frame, 40, 56);

        DrawData drawData = new DrawData(
            BodyTexture.Value,
            pos.ToFloor(),
            sourceRect,
            drawInfo.colorArmorBody,  // 受光照影响的颜色
            drawInfo.drawPlayer.bodyRotation,
            new Vector2(0.5f, 0.025f), // 锚点
            1f,
            se,
            0
        );
        drawData.shader = drawInfo.drawPlayer.cBody; // 应用染色器
        drawInfo.DrawDataCache.Add(drawData);
    }

    // 加载贴图（只加载一次）
    public override void Load()
    {
        BodyTexture = Mod.Assets.Request<Texture2D>("Items/Armors/MyChar/MyCharBody");
    }
}
```

## 五、让"选人界面"多一个按钮（不靠名字触发）

tModLoader 目前**没有官方 Hook** 直接在原版选人界面注入按钮。
有两种可行方案：

### 方案 A：在游戏内 UI 加按钮（推荐，最稳定）

进入世界后，在屏幕某处画一个按钮（用 `ModSystem` + `UIState`），玩家点击后把 `IsMyChar = true` 写进存档。

```csharp
// 伪代码框架
public class MyCharUI : UIState
{
    public override void OnInitialize()
    {
        UIImageButton btn = new UIImageButton(/* 按钮贴图 */);
        btn.OnClick += (evt, elem) =>
        {
            Main.LocalPlayer.GetModPlayer<MyCharModPlayer>().IsMyChar = true;
            // 可以在这里给玩家初始道具
        };
        Append(btn);
    }
}
```

### 方案 B：MonoGame Hook 劫持选人界面（高级，有兼容风险）

用 MonoMod/On 钩子劫持 `Main.DrawCharacterSelectUI` 或对应的方法，
在原版 UI 绘制完成后叠加绘制自己的按钮，然后检测鼠标点击。
伊蕾娜 mod 里改雨的方式（`Rain.Update +=`）就是这个思路，用在 UI 上同理。

```csharp
// Mod.Load() 里：
On.Terraria.Main.DrawCharacterSelectUI += (orig, self) =>
{
    orig(self); // 先让原版画完
    // 然后叠加你的按钮逻辑
    Vector2 btnPos = new Vector2(/* 坐标 */);
    // 绘制按钮图片 ...
    // 检测点击 ...
};
```

> **推荐方案 A**。方案 B 每次大版本更新都可能因方法签名变化而崩溃。

## 六、完整触发流程总结

```
玩家取名 "特定名字"
        │
        ▼
AddStartingItems() 或 OnEnterWorld()
→ IsMyChar = true
→ 可在此给初始道具
        │
        ▼
每帧 FrameEffects()
→ Player.head/body/legs = 你的装备槽 ID
        │
        ▼
每帧 DrawEffects()
→ drawInfo.drawPlayer.head/body/legs = 你的装备槽 ID
→ HidesTopSkin / HidesArms / HidesBottomSkin = true
→ DrawHead[slotHead] = false
        │
        ▼
渲染结果：完全显示你的贴图，原版肤色/发色/性别外观全部被遮盖
```

## 七、常见问题

**Q：为什么我的贴图显示出来有白边/颜色不对？**
A：`DrawEffects` 里用的是 `drawInfo.colorArmorBody`，这个颜色受光照影响。
如果想完全亮度自定义，在 `PlayerDrawLayer` 里用 `Color.White`，或者把 `fullBright = true`。

**Q：为什么手臂还是露出原版皮肤？**
A：`HidesArms[slotBody] = true` 要配合 `HidesTopSkin[slotBody] = true` 一起设，缺一不可。
另外注意 `DrawEffects` 每帧都要设，因为这些 Sets 是静态数组，可能被其他 mod 修改。

**Q：坐骑/坐凳状态下腿部错位？**
A：坐下时游戏调用 `DrawSittingLegs`，需要用 On 钩子劫持（参考伊蕾娜 mod 的 `Elaina_sittinglegs`），
检测到 `IsMyChar` 时手动设置 `legFrame.Y = 336`，跳过原版坐腿绘制。

**Q：多人联机时其他玩家看不到皮肤？**
A：`IsMyChar` 状态要通过 `ModPacket` 同步。在 `SyncPlayer` 里发包，在 `HandlePacket` 里接包，
把其他玩家的 `IsMyChar` 设成正确值。可参考伊蕾娜 mod 的 `MessageType.Elaina` 部分。

**Q：贴图的帧数/尺寸完全不想和原版一样怎么办？**
A：走 `PlayerDrawLayer` 路线（第四节），完全自己控制 `sourceRect` 和帧切换逻辑，不受原版帧动画约束。

## 八、最小文件清单

实现"取名触发 + 完全覆盖皮肤"只需要这些文件：

```
你的Mod/
├── MyMod.cs                        ← 注册装备贴图
├── MyCharModPlayer.cs              ← 触发 + 覆盖逻辑
└── Items/Armors/MyChar/
    ├── MyCharHead.png              ← 40×1120 px，20 帧
    ├── MyCharBody.png              ← 40×1120 px，20 帧
    └── MyCharLegs.png              ← 40×1120 px，20 帧
```

如果还要接管躯干绘制，再加：
```
├── MyCharBodyLayer.cs              ← PlayerDrawLayer
```

如果要联机同步，在 `MyMod.cs` 的 `HandlePacket` 里加同步逻辑。
