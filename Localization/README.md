# Calamity Legends Come Back

一个面向 tModLoader 的 Terraria 模组，主题是“传奇武器重做”。

本模组旨在重构并回归《灾厄》中早期版本的传奇武器体验。它不是简单复刻旧版数值，而是围绕每一把传奇武器重新设计攻击方式、成长节奏、技能机制和战斗手感，让传奇武器在整个流程中持续获得新的玩法变化。

## 模组特色

- 传奇武器重做：对传奇武器进行完整重制，而不是只做数值调整。
- 机制成长：随着游戏进度推进，逐步解锁新的攻击方式、技能和战斗逻辑。
- 多操作体系：支持左键、右键、组合操作、冲刺键和特殊技能键等更立体的战斗输入。
- 全流程适配：目标是让一把传奇武器能够贯穿多个游戏阶段，并持续保持新鲜感。
- 表现力强化：重做弹幕、特效、贴图和战斗反馈，让武器更符合“传奇”的定位。
